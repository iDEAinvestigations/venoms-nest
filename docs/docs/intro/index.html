Welcome to the Venom Suite Documentation Hub

Welcome to the comprehensive documentation for the Venom Suite - a collection of professional-grade security, intelligence, and safety applications.

What is the Venom Suite?​

The Venom Suite consists of 8 powerful Android applications designed for security professionals, investigators, law enforcement personnel, and individuals concerned about personal safety and privacy.

The 8 Products​

Our suite includes specialized tools for different security needs:

Tracking & Location Intelligence:

  • Ghost Venom - Find My network tracking and BLE scanning
  • MacVenom Pro - Professional device discovery and directional finding

Intelligence & Investigation:

  • IP Lizard - Network OSINT and IP intelligence tool
  • Socialpede - Professional OSINT investigation across 40+ platforms

Safety & Emergency Response:

  • Link Up Elite - Family safety with emergency SOS system

RF & Surveillance Detection:

  • RF Scorpion - Professional RF security and hidden device detection
  • ToadCAM - Infrared camera detection and surveillance mapping

Data Analysis & Forensics:

  • PCMD Live - Call detail record analysis and triangulation

System Requirements​

  • Android 8.0 or higher (some products require Android 12+)
  • Valid license key for each product
  • Internet connection for cloud features
  • Location services enabled for location-based features
  • Appropriate permissions (camera, microphone, Bluetooth, etc.)

Legal & Ethical Use​

All Venom Suite products are designed for legal, authorized use by:

  • ✅ Security professionals
  • ✅ Law enforcement (with proper authority)
  • ✅ Corporate security teams
  • ✅ Private investigators (with licensing)
  • ✅ Individuals protecting their own privacy

Users are responsible for complying with all applicable laws.
