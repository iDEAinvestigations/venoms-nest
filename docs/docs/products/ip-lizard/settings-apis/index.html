IP Lizard - Settings & API Configuration

Access settings by tapping the ⚙️ gear icon in IP Lizard.

General Settings​

Scan Preferences​

  • Scan Timeout: How long before scan gives up (default: 30 seconds)
  • Threads: Number of concurrent scans (1-10, default: 4)
  • Retry Failed: Retry failed IP lookups (on/off)
  • Store History: Save scan results (on/off)

Display Settings​

  • Theme: Dark Mode or Light Mode
  • Font Size: Adjust text size (small, medium, large)
  • Metric Units: Use meters instead of feet
  • Show Flags: Display country flags in results
  • Results Per Page: How many results to display at once

API Configuration​

IP Lizard uses multiple APIs for enhanced functionality:

Available APIs​

  1. MaxMind GeoIP - Geolocation data
  2. WHOIS API - Network ownership information
  3. VirusTotal - Threat intelligence
  4. AbuseIPDB - Malicious IP database
  5. IPQualityScore - IP reputation

Configuring APIs​

  1. Open Settings
  2. Tap "API Configuration"
  3. For each API, you can:
    • View current status (Active/Inactive)
    • Enter your API key
    • Test the connection
    • Enable/disable the API

Getting API Keys​

MaxMind GeoIP​

  • Visit: www.maxmind.com
  • Sign up for free account
  • Generate API key
  • Copy and paste in IP Lizard settings

WHOIS API​

  • Visit: www.whoisapi.com
  • Create account
  • Get API key
  • Enter in IP Lizard settings

VirusTotal​

  • Visit: www.virustotal.com
  • Create free account
  • Generate API key from user settings
  • Enter in IP Lizard settings

AbuseIPDB​

  • Visit: www.abuseipdb.com
  • Create account
  • Go to API settings
  • Copy key to IP Lizard

IPQualityScore​

  • Visit: www.ipqualityscore.com
  • Create account
  • Generate API key
  • Enter in IP Lizard settings

Testing API Connection​

  1. After entering API key
  2. Tap "Test Connection"
  3. App verifies the key works
  4. Status shows Success or Error

API Status Indicator​

In settings, you'll see status for each API:

StatusMeaningAction
✅ ActiveAPI is workingContinue using
⚠️ Invalid KeyKey format wrongRe-enter key
❌ No ConnectionServer unreachableCheck internet
⏳ DisabledAPI is offEnable if needed

Privacy Settings​

Data Storage​

  • Store Lookups: Save scan results locally (on/off)
  • Store IP History: Keep record of IPs looked up (on/off)
  • Auto-Delete History: Automatically delete old scans (off/7 days/30 days)
  • Backup to Cloud: Cloud backup of results (on/off)

Anonymous Scanning​

  • Use VPN: Route scans through VPN
  • Proxy Settings: Configure proxy server

Threat Intelligence Settings​

Threat Level Thresholds​

  • High Risk Threshold: When to flag IP as high risk
  • Medium Risk Threshold: When to flag as medium risk
  • Reputation Check: Enable reputation checking

Threat Sources​

Enable/disable specific threat intelligence sources:

  • ☑️ VirusTotal
  • ☑️ AbuseIPDB
  • ☑️ AlienVault OTX
  • ☑️ Shodan
  • ☑️ Custom blocklists

Export Settings​

Default Export Format​

  • Choose default format: CSV, JSON, PDF

Export Directory​

  • Select where files are saved
  • Default: Download folder
  • Can choose custom location

Auto-Export​

  • Auto-save results (on/off)
  • Auto-open exported files (on/off)
  • Export notifications (on/off)

Network Settings​

Timeout Settings​

  • Connection Timeout: How long to wait for response (5-60 seconds)
  • Read Timeout: How long to wait for data (10-120 seconds)

Proxy Settings​

If using corporate proxy:

  1. Enable "Use Proxy"
  2. Enter Proxy Host (IP or domain)
  3. Enter Proxy Port (usually 8080 or 3128)
  4. Enter Username (if required)
  5. Enter Password (if required)
  6. Tap "Test Proxy"

Notifications​

Scan Notifications​

  • Notify on Complete: Alert when scan finishes
  • Notify on Error: Alert when scan fails
  • Sound: Play notification sound
  • Vibration: Vibrate on notification

Update Notifications​

  • Check for Updates: Automatically check for new versions
  • Notify About Updates: Alert when update available
  • Auto-Update: Automatically install updates

Advanced Settings​

Debug Logging​

  • Enable Logging: Save detailed debug logs
  • Log Level: Verbose, Normal, or Minimal
  • Export Logs: Save logs for troubleshooting

Performance​

  • Cache Results: Store recent lookups for faster repeats
  • Cache Size: How many results to keep in cache
  • Clear Cache: Remove cached data

Reset Settings​

  • Reset to Defaults: Restore all original settings
  • Clear All Data: Delete all results and history

Account Settings​

License Information​

  • View current license status
  • License expiration date
  • Device binding information

About App​

  • Version: Current IP Lizard version
  • Build Number: Build identification
  • Last Updated: When app was last updated

Support & Help​

In-App Support​

  1. Tap ⚙️ Settings
  2. Scroll to bottom
  3. "Support" section provides:
    • Contact information
    • FAQ
    • Send feedback
    • Report bug
