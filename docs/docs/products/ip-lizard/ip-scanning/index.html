IP Lizard - IP Scanning & Lookups

Manual IP Lookup​

Basic IP Lookup​

  1. Open IP Lizard
  2. You'll see three main tabs: Scan, Upload, Snap Chat
  3. Tap the Scan tab (if not already selected)
  4. Enter an IP address in the search field
  5. Tap "Lookup" or press Enter
  6. Results display with:
    • Country/City location
    • Latitude/Longitude coordinates
    • ISP/Carrier information
    • ASN (Autonomous System Number)
    • Organization details

Viewing Results on Map​

  1. After lookup, tap "View on Map"
  2. The IP location displays on an interactive map
  3. Use zoom controls to see details
  4. Tap the location pin for full details

Network Scanning​

Local Network Scan​

Discover hosts and services on your local network:

  1. Tap Scan tab
  2. Tap "Network Scan"
  3. Select "Local Network"
  4. App scans your WiFi network
  5. List shows all detected devices with:
    • Device IP address
    • Hostname (if available)
    • Open ports
    • Services detected
    • Signal strength

Remote Network Scan​

To scan a remote network (with authorization):

  1. Tap Scan tab
  2. Tap "Network Scan"
  3. Select "Remote Network"
  4. Enter the network IP range (e.g., 192.168.1.0/24)
  5. Tap "Scan"
  6. Results show accessible hosts
warning

Only scan networks you have authorization to scan. Unauthorized network scanning may violate laws.

WHOIS & DNS Lookups​

WHOIS Information​

Get network ownership and administrative details:

  1. Enter IP address in search field
  2. Tap "WHOIS" button
  3. View owner organization details:
    • Organization name
    • Administrative contact
    • Technical contact
    • Mailing address
    • Phone numbers

Reverse DNS Lookup​

Find domain name for an IP address:

  1. Enter IP address
  2. Tap "Reverse DNS"
  3. Get associated domain name(s)
  4. Shows:
    • Primary domain
    • All associated domains
    • PTR record information

ASN Information​

What is an ASN?​

Autonomous System Number - unique identifier for Internet networks

ASN Lookup​

  1. Enter IP address
  2. Tap "ASN Info"
  3. View:
    • ASN Number (e.g., AS12345)
    • Organization operating the ASN
    • Country
    • IP Range covered
    • Size of network

Threat Intelligence​

Check for Known Threats​

  1. Enter IP address
  2. Tap "Threat Check"
  3. Results show:
    • ✅ Safe - No known threats
    • ⚠️ Suspicious - Some risk factors
    • 🚨 Malicious - Known threat
  4. Details on threat sources

Saving & Exporting Results​

Save IP to Favorites​

  1. After lookup, tap the ⭐ Star icon
  2. IP is saved in your Favorites
  3. Access later from Favorites tab

Export Results​

  1. Complete a lookup
  2. Tap "Export" button
  3. Choose format:
    • CSV - For spreadsheets
    • JSON - For technical analysis
    • PDF - For reports
  4. Save to device

Tips for Effective Scanning​

  • Use Correct Format: Ensure IP is valid (e.g., 8.8.8.8)
  • Check Permissions: Only scan networks you own or have permission
  • Save Results: Export findings for your records
  • Cross-Reference: Compare multiple OSINT sources
  • Document Everything: Record dates and times of scans
