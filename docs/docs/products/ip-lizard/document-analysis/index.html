IP Lizard - Document IP Extraction

Extract IP addresses from documents automatically using IP Lizard.

Supported File Types​

FormatExtensionSupport
PDF.pdfFull support
Excel.xls, .xlsxFull support
CSV.csvFull support
Word.doc, .docxFull support
Text.txtFull support

Uploading Documents​

Method 1: File Selection​

  1. Open IP Lizard
  2. Tap the "Upload" tab
  3. Tap "Select File"
  4. Browse to your document
  5. Tap the file to select
  6. Tap "Analyze"

Method 2: Drag and Drop​

  1. Open IP Lizard
  2. Tap the "Upload" tab
  3. Drag file into the drop zone
  4. App automatically begins analysis

Method 3: From Recent Files​

  1. Tap "Upload" tab
  2. If file was recently analyzed, it appears in Recent Files
  3. Tap to re-analyze

Analysis Process​

What Happens During Analysis​

  1. File Upload: Document is processed
  2. IP Extraction: All IP addresses are found and extracted
  3. Validation: IPs are verified as valid format
  4. Geolocation: Location data is retrieved
  5. Results Display: All findings displayed in results view

Processing Time​

  • Small Files (< 1MB): 5-10 seconds
  • Medium Files (1-10MB): 10-30 seconds
  • Large Files (> 10MB): 30-60 seconds

What Can Go Wrong​

  • Corrupted File: May fail to process
  • Unusual Formatting: IPs in non-standard format may be missed
  • Encrypted File: Password-protected documents won't work
  • Very Large File: May timeout (break into smaller files)

Viewing Results​

Results Display​

After analysis completes, you'll see:

ColumnInformation
IP AddressThe extracted IP
CountryGeographic location
CityCity location (if available)
ISPInternet Service Provider
TypePublic/Private IP

Sorting Results​

  • Tap column headers to sort by that field
  • Sort by Country, City, ISP, etc.
  • Helps organize large result sets

Filtering Results​

  1. Tap "Filter" button
  2. Choose filter type:
    • By Country: Show only IPs from specific country
    • By IP Type: Show only public or private IPs
    • By ISP: Show only IPs from specific ISP
  3. Results update dynamically

Working With Results​

Single IP Lookup​

For more details on any IP:

  1. Tap on an IP in the results
  2. Full details display:
    • Geolocation: Precise location
    • WHOIS Info: Network ownership
    • ASN: Autonomous System details
    • Threat Status: Known threats
  3. Tap "View on Map" to see location

Batch Operations​

Export All Results​

  1. After analysis, tap "Export All"
  2. Choose format:
    • CSV: Spreadsheet format
    • JSON: Technical format
    • PDF: Report format
  3. Results saved to device

Copy to Clipboard​

  1. Tap an IP address
  2. Tap "Copy IP"
  3. IP copied to clipboard
  4. Paste elsewhere with Ctrl+V

Export Specific IPs​

  1. Tap checkboxes next to IPs you want
  2. Tap "Export Selected"
  3. Choose format
  4. File is saved

PDF Analysis Details​

How PDF Analysis Works​

  1. Extracts all text from PDF
  2. Scans for IP-like patterns
  3. Validates found IPs
  4. Retrieves geolocation data

PDF-Specific Tips​

  • Works with text-based PDFs (not scanned images)
  • Complex PDFs may miss some IPs
  • Two-column layouts may confuse parser (try single-column PDFs)

Excel/CSV Analysis​

Analyzing Spreadsheets​

  1. Select Excel or CSV file
  2. App scans all cells for IPs
  3. Can scan multiple sheets (for Excel)
  4. Results show all found IPs

Tips for Spreadsheets​

  • Works with any cell containing IP
  • Can search specific columns if needed
  • Date-based IPs (e.g., in timestamp) may be flagged as false positives

Word Document Analysis​

Analyzing Word Files​

  1. Select .doc or .docx file
  2. App extracts text from document
  3. Searches for IP addresses
  4. Shows all found IPs

Word-Specific Features​

  • Works with text in document body
  • Includes text from tables and headers
  • Ignores formatting, focuses on content

Comparison Results​

Compare Multiple Documents​

To analyze trends across documents:

  1. Upload first document, note results
  2. Upload second document, note results
  3. Use export to get both result sets
  4. Import into spreadsheet for comparison

Finding Unique IPs​

  1. Export results from both documents as CSV
  2. Import both into spreadsheet
  3. Use spreadsheet functions to:
    • Find IPs in both files
    • Find IPs unique to each file
    • Count occurrences

Storage & History​

View Analysis History​

  1. Tap "Upload" tab
  2. Recent Files shows previously analyzed documents
  3. Tap to view previous results without re-uploading

Delete Analysis History​

  1. Tap "History" button
  2. Select files to delete
  3. Tap "Delete"
  4. History is cleared

Storage Limits​

  • Free users: Last 10 analyses
  • Pro users: Unlimited history
  • Cloud backup available (if enabled)

Troubleshooting​

File won't upload?

  • Ensure file is in supported format
  • Check file isn't corrupted
  • Try smaller file first

No IPs found?

  • Check document actually contains IPs
  • Try manual search in PDF reader
  • Some encrypted files won't work

Incorrect results?

  • PDFs with scanned images won't work (OCR not available)
  • Non-standard IP formats may be missed
  • Check results manually for accuracy
