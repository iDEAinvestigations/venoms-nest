IP Lizard License Activation

Obtaining a License​

To use IP Lizard, you must have a valid license key.

Requesting a License​

Contact the sales team:

MethodContact
EmailSales@ideatech.us
Phone708-808-0719
Websitewww.ideatech.us

Provide:

  • Your name/organization
  • Intended use (security research, admin, etc.)
  • Expected usage frequency
  • Any special requirements

License Formats​

Licenses come in different types:

TypeDurationPrice
Personal1 yearStandard
Professional1 yearHigher tier
Enterprise1-3 yearsVolume pricing

Activation Process​

Step-by-Step Activation​

  1. Receive License Key

    • You'll receive a key like: IPLI-XXXX-XXXX-XXXX-XXXX
    • Save this safely

  2. Open IP Lizard

    • Launch the app
    • If not licensed, Activation screen appears

  3. Enter License Key

    • Tap in the license key field
    • Type or paste your key
    • Ensure correct format (no spaces)

  4. Tap Activate

    • Tap the "Activate License" button
    • App connects to activation server
    • Verification takes 5-30 seconds

  5. Receive Confirmation

    • Success message appears
    • License information displays:
      • Status: ACTIVE
      • Expiration date
      • Device ID

  6. Access Full Features

    • All IP Lizard features now available
    • You can begin using the tool

License Information​

Viewing Your License​

  1. Open Settings (⚙️ icon)
  2. Tap "License Information"
  3. View:
    • Status: Active or Expired
    • Expiration Date: When license expires
    • Device ID: This device's identifier
    • License Key: Last 4 digits
    • Days Remaining: Until expiration

License Binding​

Each license key is bound to ONE device:

  • First device to activate "owns" the license
  • Cannot use on different device
  • Binds to device's unique ID
  • Cannot transfer without contacting support

Device ID​

Your device ID consists of:

  • Manufacturer
  • Device model
  • Android ID
  • Other hardware identifiers

This prevents license sharing and piracy.

Expiration & Renewal​

Approaching Expiration​

Before expiration, you'll see notifications:

  • 30 days before: Warning banner appears
  • 7 days before: Red warning message
  • Expired: App functionality limited

Renewing Your License​

When license nears expiration:

  1. Email Sales: Sales@ideatech.us
  2. Request Renewal: State your current license (last 4 digits)
  3. Provide: New license will be sent
  4. Activate: Use new key in app

What Happens When Expired​

  • Some features become read-only
  • Cannot perform new scans (previous results available)
  • Cannot export data
  • Must renew to regain full access

Troubleshooting Activation​

"License Key Invalid"​

Solutions:

  1. Check for typos in key
  2. Ensure correct format: IPLI-XXXX-XXXX-XXXX-XXXX
  3. Verify key is for IP Lizard (not other product)
  4. Contact sales if key is bad

"License Already Used"​

Meaning: Key activated on different device

Solutions:

  1. Use on original device
  2. Contact support@ideatech.us for:
    • Device re-registration
    • New key for different device

"No Internet Connection" During Activation​

Solutions:

  1. Verify internet connectivity
  2. Try WiFi instead of cellular
  3. Wait and retry after network restored
  4. Offline activation may be available (contact support)

"License Not Valid on This Device"​

Meaning: Device hardware changed or is incompatible

Solutions:

  1. Contact support@ideatech.us
  2. Provide: Current device model and Android version
  3. They may be able to re-register device

Multiple Devices​

Using on Multiple Devices​

Each device needs its own license:

  • Can't share one license across devices
  • Purchase additional licenses for additional devices
  • Contact sales for multi-device pricing

Setting Up on New Device​

  1. Get separate license key for new device
  2. Install IP Lizard on new device
  3. Activate using new license key
  4. Each device has independent data/settings

Support​

For licensing issues:

Email: Sales@ideatech.us
Phone: 708-808-0719
Website: www.ideatech.us

Provide:

  • Last 4 digits of license key
  • Device model and Android version
  • Description of issue
  • Screenshots if applicable
