Socialpede v3.0 - Professional OSINT Investigation Tool

Socialpede is a professional OSINT (Open Source Intelligence) investigation tool that aggregates multiple data sources and APIs to gather intelligence on usernames, emails, phones, IPs, locations, and images.

Core Capabilities​

Username Search​

  • 40+ Platform Search: Search across major social networks and sites
  • Account Discovery: Find accounts linked to username
  • Profile Compilation: Gather profile information from multiple sources
  • Historical Data: Track username history and changes
  • Platform Analysis: Understand user's digital footprint

Phone Number Intelligence​

  • Carrier Lookup: Identify phone carrier and type
  • Platform Search: Find accounts associated with number
  • Location History: Determine number registration location
  • Breach Detection: Check if number in data breaches
  • Privacy Analysis: Assess number's exposure

Email Investigation​

  • Breach Database: Check if email in known breaches
  • Password Strength: Evaluate compromise risk
  • Associated Accounts: Find accounts using email
  • Domain Analysis: Research email provider
  • Reputation Check: Email reputation scoring

IP Address Intelligence​

  • Geolocation: Pinpoint IP location on map
  • ISP Information: Identify internet service provider
  • VPN/Proxy Detection: Identify privacy tools
  • Threat Intelligence: Check for malicious IPs
  • Historical Data: Track IP ownership changes

Location-Based Search​

  • GPS-Based Discovery: Find social media posts from GPS coordinates
  • Reverse Geolocation: Find places mentioned in posts
  • Map Integration: Visualize search results
  • Travel Pattern Analysis: Track movement over time
  • Public Infrastructure: Find posts from landmarks

Image Analysis & OSINT​

  • EXIF Data Extraction: Get metadata from photos
  • AI Geolocation: Estimate location from image content
  • Facial Recognition: Find similar faces across internet
  • Reverse Image Search: Find original source
  • Metadata Analysis: Extract full image information

System Requirements​

  • Android 12+ (API 32+)
  • Valid Socialpede license key
  • Internet connection required
  • 200MB+ free storage
  • Location services for GPS features

Designed For​

  • ✅ Security Researchers: Authorized investigations
  • ✅ Law Enforcement: Official investigations (with proper authority)
  • ✅ Corporate Security: Employee vetting and risk assessment
  • ✅ OSINT Practitioners: Professional intelligence gathering
  • ✅ Investigators: Locate missing persons, fraud detection

Watchlist & Monitoring​

  • Save Targets: Monitor specific users/emails/IPs
  • Continuous Updates: Get alerts on new information
  • Comparison Tool: Track changes over time
  • Export Reports: Create formal documentation
  • Sharing: Export findings for team review

Main Tabs​

The app uses 8 primary tabs:

  1. Username - Search for usernames across platforms
  2. Phone - Phone number intelligence
  3. Email - Email breach and reputation
  4. IP Address - IP geolocation and analysis
  5. Location - GPS-based social media discovery
  6. Image - Photo metadata and analysis
  7. Watchlist - Monitor targets
  8. Settings - API configuration

Legal & Ethical Use​

Appropriate Uses​

  • ✅ Authorized security research
  • ✅ Official law enforcement investigations
  • ✅ Employment background checks (with consent)
  • ✅ Fraud detection
  • ✅ OSINT training and education

Inappropriate Uses​

  • ❌ Stalking or harassment
  • ❌ Unauthorized surveillance
  • ❌ Violating privacy laws
  • ❌ Malicious hacking
  • ❌ Identity theft preparation

Users must comply with all applicable laws and obtain proper authorization.
