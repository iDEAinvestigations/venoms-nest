Socialpede - Installation & License Activation

System Requirements​

  • Android: 12+ (API 32+)
  • Storage: Minimum 200MB free storage
  • RAM: 2GB minimum (4GB+ recommended)
  • Internet: Required for all API features
  • Permissions: Location (optional but recommended for GPS features)

Installation Steps​

1. Install the Application​

  1. Download the Socialpede APK file
  2. Open your file manager and navigate to Downloads
  3. Tap the Socialpede APK file
  4. Tap "Install"
  5. Wait for installation to complete
  6. Tap "Open" to launch

2. Grant Optional Permissions​

On first launch, Socialpede may request:

Location Permission (optional):

  • Tap "Allow" to enable GPS-based features
  • Used for: Location-based social media discovery
  • Can be enabled/disabled later in settings

Storage Permission (optional):

  • Tap "Allow" to save images for analysis
  • Used for: Image analysis and EXIF extraction
  • Can grant later if needed
tip

Permissions can be changed anytime in Settings > Apps > Socialpede > Permissions

License Activation​

Getting Your License Key​

To activate Socialpede, you need a license key:

  1. Contact Venom's Nest at:

    • Email: sales@ideatech.us
    • Phone: 708-808-0719
    • Website: www.ideatech.us

  2. You will receive a license key in format: XXXX-XXXX-XXXX-XXXX-XXXX

First Launch - License Check​

When you open Socialpede for the first time:

  1. License Check Screen appears
  2. If no license detected, Activation Screen displays
  3. Enter your license key
  4. Tap "Activate License"
  5. Wait for online verification
  6. Success message shows:
    • ✅ License Status: ACTIVE
    • Activation Date
    • Expiration Date
  7. Tap "Continue to App" to access main interface

License Information​

License Binding:

  • Each license key bound to ONE device only
  • First device to activate owns the license
  • Device fingerprint includes:
    • Android ID
    • Device Manufacturer
    • Device Model

License Expiration:

  • Valid for specific time period
  • 30 days before expiry: Warning banner appears
  • Red warning: 7 days or less remaining
  • Orange warning: 14 days or less remaining

Renewal:

  • Contact support: support@ideatech.com
  • Renew before expiration
  • Or reactivate with new key

Accessing License Information​

View License Details​

From More tab (Settings):

  1. Tap "License Information" or "Settings"
  2. View license details:
    • License Tier (Free/Standard/Professional/Enterprise)
    • Customer ID
    • Status (Active/Expired/Expiring Soon)
    • Activation Date
    • Expiration Date
    • Device Binding

Setting Up API Keys​

Why API Keys?​

Some Socialpede features require external API keys:

  • Google Geolocation API - Image location analysis
  • OpenAI/Anthropic API - AI image analysis
  • FaceCheck.ID API - Face recognition search
  • Shodan API - Internet camera scanning (related tools)

Configure API Keys​

To access API settings:

  1. Tap "More" tab (usually bottom right)
  2. Tap "Settings" or "Preferences"
  3. Look for "API Configuration" or "API Keys"
  4. Enter your API keys:
    • Paste key from service
    • Save settings

Verification & First Launch​

Verify Installation​

After activation, check that everything is working:

1. Test Username Search:

  • Go to Username tab
  • Search for a known username (e.g., "twitter" or "reddit")
  • Results should appear
  • Indicates app is functioning

2. Test Phone Lookup:

  • Go to Phone tab
  • Enter a valid phone number
  • Basic carrier lookup should work
  • (No API key required for basic lookup)

3. Test Email Check:

  • Go to Email tab
  • Enter any email address
  • Reputation score should display
  • (No API key required for basic check)

Common First Launch Issues​

"License validation failed":

  • Check internet connection is active
  • Verify license key is entered correctly (case-sensitive)
  • Try activating again in a few minutes
  • Server may be temporarily busy

"License already used on another device":

  • License tied to one device
  • To use on new device, contact support
  • They can reset binding for you

"Device not compatible":

  • Requires Android 12+
  • Check your Android version: Settings > About > Android Version
  • Update Android if possible
  • Or use compatible device

Troubleshooting Installation​

App Won't Install​

"Installation blocked" message:

  1. Go to Settings > Security
  2. Enable "Unknown Sources" or "Install unknown apps"
  3. Select ToadCAM app from security settings
  4. Tap "Allow" for installation
  5. Retry installation

App Crashes on Launch​

After installation or license activation:

  1. Check Storage: Need at least 200MB free

    • Go to Settings > Storage
    • Delete unnecessary files if needed

  2. Clear App Cache:

    • Settings > Apps > Socialpede > Storage > Clear Cache

  3. Restart Device:

    • Restart your Android device
    • Reopen Socialpede

  4. Reinstall App:

    • Uninstall Socialpede
    • Download fresh APK
    • Reinstall from scratch

Permission Issues​

If features request permissions repeatedly:

  1. Go to Settings > Apps > Socialpede
  2. Tap "Permissions"
  3. Grant each permission:
    • Location - For GPS-based search
    • Storage - For image analysis
    • Camera - For direct photo capture
  4. Return to Socialpede
  5. Try feature again
