Socialpede Troubleshooting & Best Practices

Common Issues & Solutions​

License & Activation Issues​

"License validation failed" error:

Solutions:

  1. Check internet connection is active
  2. Verify license key is correct (case-sensitive)
  3. Ensure key hasn't been used on another device already
  4. Try activating again after a few minutes
  5. Contact support if still failing: support@ideatech.com

"License already used on another device":

Each license key bound to ONE device only.

Solutions:

  1. Contact support: support@ideatech.com
  2. Provide:
    • Your license key
    • Original device info
    • New device info
  3. Support can reset device binding
  4. Re-activate on new device

"License expired" warning:

License expiration approaching:

  • Red warning = 7 days or less
  • Orange warning = 14 days or less

What to do:

  1. Contact support for renewal: support@ideatech.com
  2. Request new license key
  3. Note your license tier
  4. Provide customer ID
  5. Activate new key in app

Search Features Not Working​

"No results found" when searching:

Possible causes:

  • Username genuinely doesn't exist
  • Network issue (offline)
  • API temporarily down
  • Rate limiting (too many searches)

Solutions:

  1. Check internet connection
  2. Try different username spelling
  3. Wait 15-30 minutes before retrying
  4. Try searching for different user
  5. If nothing works, contact support

"API error" or "Connection failed":

Causes:

  • No internet connection
  • API service temporarily down
  • Firewall blocking requests
  • VPN interference

Solutions:

  1. Disable VPN if using one
  2. Switch from WiFi to cellular or vice versa
  3. Check internet connection (try web browser)
  4. Restart app
  5. Restart phone if still not working

Phone lookup shows no carrier:

Possible reasons:

  • Invalid phone number format
  • Number doesn't exist
  • Number too new (not yet indexed)
  • International number unsupported

Solutions:

  1. Try different phone formats:
    • +1-555-123-4567
    • (555) 123-4567
    • 5551234567
  2. Verify number is valid
  3. Try a different phone number to test
  4. Check if international numbers supported

API & Configuration Issues​

"Invalid API key" error:

Causes:

  • API key copied incorrectly
  • API key expired
  • API key has insufficient permissions
  • Wrong API key for service

Solutions:

  1. Verify API key is correct
  2. Copy directly from service dashboard (not from email)
  3. Check API service for key expiration
  4. Generate new API key if expired
  5. Ensure key has required permissions

"Rate limited" or "Quota exceeded":

API usage limits exceeded.

Solutions:

  1. Wait before making more requests
    • Hourly limits reset at next hour
    • Daily limits reset at midnight
    • Monthly limits reset on 1st of month
  2. Check your API usage dashboard
  3. Upgrade API plan for higher limits
  4. Spread searches over time instead of bulk

API not showing results:

Possible reasons:

  • API key not configured
  • API key invalid
  • API service down
  • No data available

Solutions:

  1. Go to More > Settings > API Keys
  2. Verify API key is entered
  3. Test API in external dashboard
  4. Try again later if service down
  5. Check if data available for search term

Breach Database Issues​

"Have I Been Pwned API not working":

Causes:

  • HIBP API key not configured
  • HIBP API key invalid
  • Rate limited by HIBP
  • Service temporarily down

Solutions:

  1. Go to haveibeenpwned.com
  2. Generate new API key
  3. Paste in Socialpede settings
  4. Test with known compromised email
  5. Wait before retrying if rate limited

Email shows no breaches but I think it's been hacked:

Reasons:

  • Email hasn't been in public breaches
  • Breach not yet indexed
  • Data breach was private (not public)
  • Wrong email address

What to do:

  1. Change password immediately
  2. Enable 2-factor authentication
  3. Monitor account for suspicious activity
  4. Check breach alert services (have I been pwned, etc.)
  5. Contact email provider about security

Location Search Issues​

Location-based search won't work:

Causes:

  • Location permission denied
  • GPS not enabled
  • No internet connection
  • No posts found at location

Solutions:

  1. Enable Location Services:
    • Settings > Location > Toggle ON
    • Select "High Accuracy" mode
  2. Grant Permission:
    • Settings > Apps > Socialpede > Permissions > Location
    • Set to "Allow all the time"
  3. Improve GPS Lock:
    • Move outdoors
    • Away from buildings
    • Wait 30+ seconds for lock
  4. Check Internet: WiFi or cellular active

Finds posts but wrong location:

Reasons:

  • GPS inaccuracy
  • User's location tag inaccurate
  • Network IP-based location (approximate)
  • Social media timestamp vs actual location

What to do:

  1. Improve GPS accuracy (high accuracy mode)
  2. Increase search radius
  3. Check post source for accuracy
  4. Note GPS is approximate

Image Analysis Issues​

"No EXIF data found":

Causes:

  • Image has EXIF stripped
  • Screenshot (no EXIF)
  • Social media download (EXIF removed)
  • Camera EXIF disabled

Why it happens:

  • Most social media removes EXIF
  • Screenshots never have EXIF
  • Images from web often cleaned
  • Privacy tools strip EXIF

What to do:

  1. Use original camera files if possible
  2. Try different image source
  3. Expect EXIF data only on original photos
  4. Download from reliable source

"Face recognition won't work" or "No matches found":

Possible reasons:

  • FaceCheck.ID API not configured
  • No credits available
  • Face too blurry or small
  • Face not searchable online
  • No API key configured

Solutions:

  1. Configure FaceCheck.ID API key in settings
  2. Check account has credits
  3. Use clear face photos (front-facing)
  4. Face must be at least 100 pixels
  5. Try different photo if no matches

AI geolocation not available:

Causes:

  • OpenAI/Anthropic API not configured
  • No API credits available
  • Image unsuitable for analysis
  • API service error

Solutions:

  1. Configure API key in settings
  2. Get API credits (free trial available)
  3. Use images with visible landmarks
  4. Ensure good image quality
  5. Check API dashboard for issues

Watchlist Not Working​

Watchlist not finding users:

Causes:

  • Username spelled differently
  • User deleted account
  • User hasn't posted recently
  • Auto-monitor disabled

Solutions:

  1. Verify spelling of username
  2. Try searching manually to confirm account exists
  3. Enable auto-monitor
  4. Manually search from search tabs
  5. Check recent vs all time posts

Auto-monitor not sending alerts:

Possible reasons:

  • Auto-monitor disabled
  • Location permission denied
  • App not running
  • User hasn't posted nearby

What to do:

  1. Go to watchlist entry
  2. Toggle Auto-Monitor ON
  3. Grant location permission
  4. Keep app running (at least in background)
  5. User must post to trigger alert

Best Practices​

Search Efficiency​

For Username Searches:

  • Try common variations (underscore, numbers, dots)
  • Start broad, then filter by platform
  • Save successful finds to watchlist
  • Document findings

For Email Searches:

  • Try with/without + addressing
  • Include password history if known
  • Monitor for new breaches
  • Set up watchlist for notifications

For Phone Lookups:

  • Verify format is correct
  • Try with/without country code
  • Note time-sensitive (numbers reassigned)
  • Cross-reference with other searches

Privacy Protection​

When Searching:

  • Use VPN to protect your privacy
  • Don't leave logged-in accounts open
  • Disable location tracking if not needed
  • Clear browser history regularly
  • Use incognito mode for sensitive searches

When Sharing Findings:

  • Never publicly share personal data
  • Use secure communication
  • Get authorization before sharing
  • Document consent
  • Follow all privacy laws

API Management​

Keep Costs Low:

  • Monitor API usage regularly
  • Set up usage alerts if available
  • Batch searches instead of individual
  • Use free features first
  • Consolidate to fewer APIs if possible

API Key Security:

  • Never share API keys
  • Rotate keys regularly
  • Delete unused keys
  • Monitor for suspicious usage
  • Store safely (not in screenshots)

Investigation Best Practices​

Verify Findings:

  • Cross-reference multiple searches
  • Confirm with manual checking
  • Check timestamps for accuracy
  • Don't rely on single source
  • Verify EXIF data accuracy

Document Work:

  • Take screenshots
  • Note search criteria
  • Record timestamps
  • Save findings
  • Create investigation report

Ethical Searching:

  • Only investigate authorized targets
  • Respect privacy laws
  • Don't share findings publicly
  • Report serious findings to authorities
  • Follow professional ethics

Performance Optimization​

Speed Up Searches​

  1. Reduce Network Load:

    • Close other apps
    • Disable background apps
    • Free up bandwidth
    • Move closer to router

  2. Reduce Device Load:

    • Close unnecessary tabs
    • Restart phone periodically
    • Free up storage
    • Update app to latest version

  3. Optimize Searches:

    • Search one feature at a time
    • Batch similar searches
    • Use filters to narrow results
    • Avoid searches during peak times

Battery Optimization​

  • Disable auto-monitor when not needed
  • Reduce location checking frequency
  • Lower screen brightness
  • Use WiFi instead of cellular
  • Close app when not actively using

Troubleshooting Workflow​

If something doesn't work:

  1. Check Basics:

    • Internet connection active?
    • App updated to latest version?
    • License valid and activated?
    • Required permissions granted?

  2. Try Simple Fixes:

    • Restart the app
    • Restart your phone
    • Clear app cache
    • Disable/enable WiFi

  3. Check Specific Feature:

    • API key configured (if needed)?
    • API has credits available?
    • Search term valid/correct?
    • Location/permissions enabled?

  4. Advanced Fixes:

    • Clear app data and reinstall
    • Try on different WiFi/connection
    • Check API service status
    • Update Android OS

  5. Get Help:

    • Contact support: support@ideatech.com
    • Include error messages
    • Provide device/app info
    • Describe steps taken

Contact Support​

If issues persist:

Email: support@ideatech.com Phone: 708-808-0719 Website: www.ideatech.us

Include in support request:

  • Your license key or customer ID
  • Device model and Android version
  • Socialpede version number
  • Exact error message
  • Steps you've already tried
  • Screenshots if applicable
