Username Search - Finding Accounts​

Purpose​

Search for a specific username across 40+ social media, professional, and gaming platforms in real-time.

How to Use​

Basic Search:

  1. Navigate to Username tab
  2. Enter the target username in search field
  3. Tap Search button
  4. Results display immediately with status for each platform

Platforms Searched​

Social Media (10 platforms):

  • Twitter/X
  • Instagram
  • Facebook
  • TikTok
  • Reddit
  • Snapchat
  • Pinterest
  • Tumblr
  • YouTube
  • Telegram

Professional (9 platforms):

  • LinkedIn
  • GitHub
  • GitLab
  • Bitbucket
  • Medium
  • Stack Overflow
  • Dev.to
  • Behance
  • Dribbble

Gaming (4 platforms):

  • Steam
  • Twitch
  • Discord
  • Roblox

Filter By Category​

Instead of searching all platforms:

  1. Tap filter button or category selector
  2. Choose category:
    • All (default - all 40+ platforms)
    • Social Media (10 platforms)
    • Professional (9 platforms)
    • Gaming (4 platforms)
  3. Search runs on selected category only
  4. Results show relevant platform results

Interpreting Results​

Each result shows:

FieldMeaning
Platform NameWhere the profile was found
StatusFound / Not Found / Error
UsernameExact username on platform
Display NameFull name shown on profile
Profile LinkURL to profile (if found)

Result Indicators:

  • 🟢 GREEN / Found - Profile exists on platform
  • 🔴 RED / Not Found - Username not registered
  • ⚠️ GRAY / Error - Unable to check (rate limited, API down, etc.)

Actions​

Tap any result to:

  • Open profile in browser
  • View full profile details
  • Save to watchlist
  • Copy profile URL
  • Share findings

No API Key Required​

Username search is built-in:

  • ✅ No API key needed
  • ✅ No setup required
  • ✅ Completely free
  • ✅ Uses direct platform checks

Phone Number Intelligence​

Purpose​

Identify carrier information and find accounts associated with a phone number.

How to Use​

Basic Lookup:

  1. Navigate to Phone tab
  2. Enter phone number in search field
  3. Supports multiple formats:
    • +1-555-123-4567
    • (555) 123-4567
    • 555-123-4567
    • 5551234567
  4. Tap Search
  5. Results display carrier and platform info

Information Retrieved​

Basic Carrier Lookup (Free):

  • ✅ Carrier name (Verizon, AT&T, T-Mobile, etc.)
  • ✅ Line type (Mobile, Landline, VoIP)
  • ✅ Location / Area code
  • ✅ Country

Platform Checks (Free):

  • ✅ WhatsApp account
  • ✅ Telegram account
  • ✅ Signal account
  • ✅ Viber account
  • ✅ Cash App account

Enhanced Lookup (Requires API Key)​

For more detailed information, add API keys:

NumVerify API:

  • More detailed carrier information
  • Phone number validation
  • Formatting and type checking
  • Free tier: 100 lookups/month

Twilio API:

  • Advanced carrier data
  • Higher accuracy
  • Custom lookup options
  • Paid service

Truecaller API:

  • Spam detection
  • Account associations
  • Confidence ratings
  • Requires Truecaller Pro

Configuring API Keys​

To enable enhanced lookups:

  1. Go to More > Settings > API Keys
  2. Find Phone Lookup or NumVerify
  3. Paste your API key
  4. Save settings
  5. Enhanced data now available

Result Interpretation​

Carrier Information:

  • Shows major US carriers and international carriers
  • Identifies if mobile, landline, or VoIP
  • Area code shows where number registered
  • Country field shows origin country

Account Findings:

  • Indicates if phone linked to messaging apps
  • Shows platform presence (not account contents)
  • Helps understand phone's digital footprint

Email Investigation​

Purpose​

Check email reputation and search breach databases for compromised credentials.

How to Use​

Basic Email Lookup:

  1. Navigate to Email tab
  2. Enter email address
  3. Tap Search
  4. Results show reputation and breach status

Free Email Features​

EmailRep.io Check (No API Key):

  • Reputation score (High / Medium / Low)
  • Suspicious activity detection
  • Reference count (mentions across web)
  • Summary of findings

BreachDirectory Check (No API Key):

  • Number of known breaches
  • Sources where email appears
  • Quick breach overview

Breach Database Features (Requires API Key)​

Have I Been Pwned ($3.50/month):

  • Comprehensive breach database
  • 10+ billion compromised accounts
  • Detailed breach information:
    • Breach name
    • Date of breach
    • Exposed data types
    • Service affected
  • Most accurate breach detection

Configuring Breach API​

To enable Have I Been Pwned lookups:

  1. Go to https://haveibeenpwned.com
  2. Register for API access
  3. Go to More > Settings > API Keys
  4. Paste HIBP API key
  5. Email searches now show breach details

IP Address Lookup​

Also on Email tab - IP investigation:

  1. Find IP Address Lookup section
  2. Enter IP address
  3. Tap Search
  4. Results show:
    • Geolocation (City, Region, Country)
    • ISP (Internet Service Provider)
    • Organization name
    • VPN/Proxy detection
    • Threat intelligence (if available)

Result Interpretation​

Email Reputation Levels:

  • 🟢 High - Trustworthy email
  • 🟡 Medium - Mixed reputation
  • 🔴 Low - Suspicious or compromised

Breach Indicators:

  • Number shown = instances email appears
  • Multiple breaches indicate security risk
  • Recent breaches more concerning
  • Recommend password change if found

IP Information:

  • ISP shows internet provider
  • VPN flag indicates proxy/privacy service
  • Geolocation approximate (can be inaccurate)
  • Used for threat assessment

Google Dorking Tool​

Purpose​

Generate advanced Google search queries for OSINT research.

How to Use​

Generate a Dork Query:

  1. Navigate to Dork tab
  2. Select category from 9 available types
  3. Enter search term
  4. Tap "Generate Dork"
  5. Choose search engine:
    • Google
    • Bing
    • DuckDuckGo
  6. Either:
    • Open in Browser - Executes search
    • Copy to Clipboard - For manual use

9 Dork Categories​

CategoryPurpose
EmailFind email addresses across web
UsernameSearch multiple platforms for username
PhoneFind phone number variations
PersonFull name across social networks
LocationCheck-ins and geotagged posts
FilesDocuments containing keywords
SocialComprehensive platform aggregation
BreachPaste sites and leak forums
AdvancedCustom dork builder

Example Generated Queries​

Email Dork:

"user@example.com" (site:linkedin.com OR site:facebook.com OR filetype:pdf)

Username Dork:

"john_doe" (site:twitter.com OR site:instagram.com OR site:github.com)

Phone Dork:

("+1-555-1234" OR "5551234" OR "555-1234") site:facebook.com

Advanced Dork Builder​

For custom queries:

  1. Select "Advanced" category
  2. Build custom dork using operators
  3. Mix operators for specific searches
  4. Test with different search engines
  5. Copy for manual searching

Legal & Ethical Considerations​

Appropriate Uses​

✅ OK to search:

  • Your own accounts
  • Public information only
  • Authorized security research
  • Due diligence investigations
  • Personal privacy assessment

Inappropriate Uses​

❌ NOT OK:

  • Unauthorized hacking
  • Stalking or harassment
  • Privacy violations
  • Impersonation
  • Harassment campaigns
