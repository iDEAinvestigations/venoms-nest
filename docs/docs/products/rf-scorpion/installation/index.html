RF Scorpion - Installation & License Activation

System Requirements​

  • Android: 8.0 (Oreo) or higher
  • Storage: Minimum 200MB free storage
  • Permissions Required:
    • Location (for cellular and Wi-Fi scanning)
    • Bluetooth (for tracker detection)
    • Phone State (for cellular network data)
    • Microphone (for audio bug detection)
    • Wi-Fi (for network scanning)

Installation Steps​

1. Install the Application​

  1. Download the RF Scorpion APK file
  2. Open your file manager and navigate to the Downloads folder
  3. Tap the RF Scorpion APK file
  4. Tap "Install"
  5. Wait for installation to complete
  6. Tap "Open" to launch the app

2. Grant Permissions​

On first launch, RF Scorpion requests permissions:

  • Location: Tap "Allow" to enable cellular tower scanning
  • Bluetooth: Tap "Allow" to detect hidden trackers
  • Phone State: Tap "Allow" to read cellular band information
  • Microphone: Tap "Allow" for audio bug detection
  • Wi-Fi: Tap "Allow" for network scanning
tip

You can change permissions later in Android Settings > Apps > RF Scorpion > Permissions

License Activation​

Obtaining Your License Key​

  1. Contact Venom's Nest at:

    • Email: sales@ideatech.us
    • Phone: 708-808-0719
    • Website: www.ideatech.us

  2. You will receive a license key in the format: XXXX-XXXX-XXXX-XXXX

Activating Your License​

  1. Launch RF Scorpion
  2. The Activation Screen will appear
  3. Enter your license key in the text field
  4. Tap "Activate License"
  5. Wait for online verification
  6. Upon success, you'll see:
    • ✅ License Status: ACTIVE
    • Activation Date
    • Expiration Date
  7. Tap "Continue to App" to access all features

License Binding​

  • Each license key is bound to ONE device only
  • The first phone to activate with a code owns that license
  • The app uses device fingerprinting including:
    • Android ID
    • Manufacturer
    • Device Model
warning

Attempting to use the same license on a different device will fail. If you need to transfer the license, contact support.

Verification​

After successful activation, verify setup:

Check Hardware Support​

From the main menu:

  1. Navigate to "GPS Trackers & Skimmers" section
  2. Check "Hardware Status Panel" showing available features:
    • ✅ Wi-Fi - 2.4/5 GHz scanning available
    • ✅ Bluetooth - Classic device detection available
    • ✅ BLE - Bluetooth Low Energy scanning available
    • ✅ Microphone - Audio bug detection available

Test Basic Scanning​

  1. Tap on "Tower Survey"
  2. Tap "Scan LTE" for a quick test scan
  3. You should see nearby cellular towers appear
  4. If no towers appear, check:
    • Location permission is enabled
    • Location services are ON in Android settings
    • You're in an area with cellular coverage

Troubleshooting Installation​

"Installation blocked" Message​

  • Go to Settings > Security
  • Enable "Unknown Sources" or "Install unknown apps"
  • Retry installation

App Crashes on Launch​

  • Ensure you have at least 200MB free storage
  • Clear app cache: Settings > Apps > RF Scorpion > Storage > Clear Cache
  • Restart your device

License Won't Activate​

  • Check internet connection is active
  • Ensure you entered the license key correctly (case-sensitive)
  • Try activating again in a few minutes (may be a server delay)
  • Contact support: sales@ideatech.us

Permissions Not Working​

  • Go to Settings > Apps > RF Scorpion > Permissions
  • Manually enable each required permission
  • Restart RF Scorpion
