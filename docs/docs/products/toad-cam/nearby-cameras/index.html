Nearby Cameras - Network & Internet Camera Detection

The Nearby Cameras feature helps you discover cameras connected to your local network and locate exposed cameras on the internet.

Opening Nearby Cameras​

From Main Menu:

  1. Tap "NEARBY CAMERAS" button (gray button)
  2. Allow location permission if prompted
  3. Scanning begins automatically
  4. Results display on Map View (default)

Understanding the Display​

Map View (Default)​

The interactive map shows:

Your Location:

  • 🔵 Blue dot = Your current position
  • Updated with GPS data
  • Used as reference point

Camera Markers:

  • 🔵 BLUE - Local network cameras (on your WiFi)
  • 🟢 GREEN - High confidence internet cameras
  • 🟠 ORANGE - Vendor-identified cameras
  • 🔴 RED - Other cameras or unknown type

Map Controls:

  • Pinch to zoom in/out
  • Drag to pan around map
  • Tap marker for camera details
  • Long-press for marker menu

List View​

Alternative view showing all cameras in scrollable list:

To Switch to List View:

  1. Look for toggle button (lower right of screen)
  2. Tap to switch from Map to List
  3. Shows all cameras including those without GPS

List Shows:

  • Camera name
  • Camera type
  • Distance from you
  • Signal strength/confidence
  • Camera manufacturer

To Switch Back to Map:

  • Tap toggle button again
  • Returns to map display

Camera Types & What They Mean​

Local Network Cameras​

🔵 BLUE Markers = Cameras on your WiFi network

What they are:

  • IP cameras connected to your home/office Wi-Fi
  • Baby monitors connected to network
  • Doorbell cameras (Ring, Nest, etc.)
  • Security system cameras
  • Other networked cameras

Why detected:

  • Scanning your local network for cameras
  • Finding ONVIF-compliant devices
  • Discovering devices on standard ports

Normal findings:

  • Your own cameras are expected
  • Known devices in your network
  • Legitimate security equipment

Suspicious findings:

  • Unknown cameras on your network
  • Cameras you didn't install
  • Devices with no obvious purpose

Internet Cameras​

🟢 GREEN Markers = High confidence internet cameras

What they are:

  • Exposed cameras found via internet search
  • Cameras accessible from internet
  • Possibly unsecured devices
  • May have default credentials

Why concerning:

  • May be exposed accidentally
  • Could have default passwords
  • May allow unauthorized access
  • Privacy violation risk

🟠 ORANGE Markers = Vendor-identified cameras

What they are:

  • Cameras identified by manufacturer
  • Recognized camera brands
  • Known security equipment
  • Identified through API lookups

How identified:

  • Vendor signature recognition
  • Known IP address ranges
  • Camera firmware identification
  • API database matches

🔴 RED Markers = Other cameras

What they are:

  • Unconfirmed cameras
  • Unknown device types
  • Uncertain classifications
  • Potential cameras

What to do:

  • Manually investigate
  • Check device details
  • Verify legitimacy
  • Only investigate your own networks

Searching for Cameras​

Automatic Scan​

When you open Nearby Cameras:

  • Scan automatically begins
  • Scans your local WiFi network
  • Queries internet APIs (if configured)
  • Results appear as markers

Manual Refresh​

To scan again:

  1. Tap search button (typically refresh icon)
  2. Scan starts over
  3. Progress indicator shows status
  4. Results update as found

What Gets Scanned​

Local Network Scan:

  • Your WiFi network
  • Connected IP addresses
  • Open ports (80, 554, 8080, etc.)
  • ONVIF devices
  • RTSP streams

Internet APIs:

  • Shodan database (if key configured)
  • Censys database (if key configured)
  • Other camera databases
  • Public IP lookup services

Filtering Results​

The filter button (funnel icon) lets you filter results:

Filter Options​

All Cameras - Show everything found

Local Network Only - Just WiFi cameras

  • Cameras on your network only
  • Excludes internet cameras
  • Good for auditing home network

Internet Cameras Only - From APIs

  • Remote cameras only
  • Excludes your local network
  • Helps find exposed devices

IP Cameras - Standard IP cameras

  • ONVIF-compliant cameras
  • Standard video streams
  • Professional security cameras

RTSP Cameras - Streaming cameras (port 554)

  • RTSP stream format
  • Network video streaming
  • Baby monitors, professional cameras

High Confidence Only - Most likely real cameras

  • Verified cameras
  • Highest confidence detections
  • Reduces false positives

Applying Filters​

  1. Tap filter button (funnel icon)
  2. Select desired filter
  3. Results update immediately
  4. Active filter shown at top

Tap a Marker​

When you tap a camera marker:

  • Info popup appears
  • Shows camera details
  • Provides action options

Available Actions​

View Details:

  • Full information about camera
  • All available metadata
  • Connection information

Open in Browser:

  • Attempt to access camera interface
  • May show live view
  • May require authentication
  • WARNING: Only do on your own cameras!

Open in Maps:

  • Show camera location on Google Maps
  • Get directions to location
  • Understand surveillance coverage
  • Geographic intelligence

Save Location:

  • Bookmark camera location
  • Add to favorites
  • Track multiple locations
  • Export for report

Report Camera:

  • Flag suspicious camera
  • Send to ToadCAM database
  • Help map surveillance
  • Community contribution

Local Network Scanning Details​

How Local Scan Works​

  1. Discovers Devices: Finds all devices on your WiFi

  2. Probes Ports: Checks common camera ports:

    • 80 (HTTP)
    • 554 (RTSP)
    • 8080 (HTTP alternative)
    • 3000-3100 (Various cameras)
    • 5000-5100 (Various cameras)

  3. Identifies Cameras: Looks for:

    • ONVIF protocol support
    • RTSP stream availability
    • Common camera signatures
    • Manufacturer identifiers

  4. Returns Results: Lists all found cameras

What to Expect​

Normal Network Results:

  • Your own security cameras
  • Smart home devices (thermostats, etc.)
  • Connected printers
  • WiFi speakers/displays
  • Other smart devices

Suspicious Results:

  • Cameras you don't recognize
  • Hidden network cameras
  • Devices you didn't install
  • Cameras from previous tenants (in rentals)

Checking Connections​

For each camera found:

  • Try to access web interface
  • Look for default credentials
  • Check manufacturer support page
  • Identify camera model
  • Change default passwords if yours

Internet Scanning Details​

How Internet Scan Works​

If you've configured API keys:

  1. Query Shodan/Censys: Search public databases
  2. Lookup Public IP: Find exposed cameras
  3. Correlate with Location: Match to your area
  4. Rate Confidence: Assess likelihood

Configuring API Keys​

To enable internet scanning:

  1. Go to SETTINGS
  2. Find "API Keys" or "API Configuration"
  3. Enter your API keys:
    • Shodan API key (free tier available)
    • Censys API key (registration required)
  4. Save settings

Interpreting Results​

Internet cameras near you may be:

  • Legitimate business cameras
  • Traffic cameras (city owned)
  • Store surveillance (public business)
  • Coincidental location matches

Only investigate cameras on YOUR network/property

  • Don't hack or access others' cameras
  • Unauthorized access is illegal
  • Report exposed cameras to authorities

Safety & Legal Considerations​

Legal Usage​

✅ OK to do:

  • Scan your own home network
  • Check your own property
  • Audit networks you own/manage
  • Document your own cameras

❌ NOT OK to do:

  • Access cameras without permission
  • Hack into camera systems
  • Scan others' networks
  • Monitor other people's devices
  • Use default credentials on unknown cameras

Privacy Concerns​

Be aware that:

  • Cameras may be recording in public
  • Some surveillance is legal
  • Traffic/business cameras are normal
  • Document findings responsibly

Troubleshooting​

Scan Finds No Cameras​

Possible reasons:

  • No cameras on your network
  • Cameras offline or not connected
  • Cameras on different network
  • API keys not configured

Solutions:

  • Manually check if cameras connected
  • Ensure they're on same WiFi
  • Restart cameras and retry
  • Configure API keys for internet scan

Scan Takes Too Long​

Reasons:

  • Large network (many devices)
  • Slow internet connection
  • API servers responding slowly
  • Port scanning taking time

Solutions:

  • Close other apps
  • Try again later
  • Reduce area of network being scanned
  • Check internet connection

False Positives (Things That Aren't Cameras)​

Common false positives:

  • Network printers
  • Smart speakers
  • WiFi routers
  • Thermostats
  • Network switches

How to verify:

  • Check device name
  • Note IP address
  • Research unknown devices
  • Test connection to device
