ToadCAM - Installation & Setup Guide

System Requirements​

  • Android: 8.0 (Oreo) or higher
  • Storage: Minimum 150MB free storage
  • Camera: Infrared-capable phone camera (most modern phones)
  • Permissions: Camera, Location
  • Features: Valid ToadCAM license key recommended for all features

Installation Steps​

1. Install the Application​

  1. Download the ToadCAM APK file
  2. Open your file manager and navigate to Downloads
  3. Tap the ToadCAM APK file
  4. Tap "Install"
  5. Wait for installation to complete
  6. Tap "Open" to launch

2. Grant Required Permissions​

On first launch, ToadCAM requests permissions:

Camera Permission:

  • Tap "Allow" to use phone camera for IR scanning
  • Required for: IR Camera Scanner feature

Location Permission:

  • Tap "Allow" to enable location services
  • Required for: Nearby Cameras detection and DeFlock ALPR mapping
  • Choose "Allow all the time" for best results
tip

You can change permissions anytime in Settings > Apps > ToadCAM > Permissions

First Launch​

License Check​

When you open ToadCAM:

  1. If you have a license key:

    • Enter your activation key
    • Tap "Activate"
    • Wait for verification
    • You'll see license status and expiration date

  2. If you don't have a license:

    • Free features remain available:
      • ✅ IR Camera Scanner
      • ✅ Basic nearby camera detection
    • Premium features require license:
      • ❌ Enhanced API searches
      • ❌ DeFlock ALPR map
      • ❌ Advanced filtering

Main Menu​

After activation, you'll see the main menu with five options:

Getting a License Key​

  2. Receive license key in format: XXXX-XXXX-XXXX-XXXX

Activating Your License​

  1. From main menu, tap "SETTINGS"
  2. Tap "License" or "Activation"
  3. Paste your license key
  4. Tap "Activate License"
  5. Wait for online verification
  6. Confirmation shows:
    • ✅ License Status: ACTIVE
    • Activation Date
    • Expiration Date
  7. Close settings to return to main menu

License Details​

  • Binding: Each license tied to one device
  • Device Fingerprint: Android ID, Manufacturer, Model
  • Transfer: Contact support if moving licenses
  • Expiration: Renewals available before expiration

Camera Verification​

Check Phone Camera Quality​

ToadCAM works best on phones with:

  • ✅ Modern camera sensors
  • ✅ IR LED capability detection
  • ✅ Good low-light performance
  • ✅ Adjustable camera focus

To verify your camera:

  1. From main menu, tap "START SCAN"
  2. Point camera at various surfaces
  3. The live preview shows your camera's IR sensitivity
  4. Better quality shows:
    • Clear image
    • Good low-light visibility
    • Bright IR LED detection

Camera Limitations​

Some older phones may have:

  • ❌ Limited IR sensitivity

  • ❌ Poor IR LED detection

  • ❌ Darker IR image

  • ❌ Difficulty focusing on IR

  • Most modern flagship phones work well

  • Mid-range phones usually adequate

  • Older phones may struggle

Permission Troubleshooting​

Camera Permission Issues​

If "Cannot access camera" message appears:

  1. Go to Settings > Apps > ToadCAM > Permissions
  2. Tap "Camera"
  3. Select "Allow"
  4. Return to ToadCAM
  5. Try opening scanner again

Location Permission Issues​

If location scanning not working:

  1. Enable Location Services:

    • Open Settings > Location
    • Toggle Location ON
    • Select "High Accuracy" mode

  2. Grant Location Permission:

    • Settings > Apps > ToadCAM > Permissions
    • Tap "Location"
    • Select "Allow all the time" (not just "while using app")

  3. Improve GPS Lock:

    • Move outdoors
    • Remove metallic case
    • Wait 30+ seconds for GPS lock

Settings Configuration​

Basic Settings​

Tap "SETTINGS" from main menu to access:

Camera Settings:

  • Filter preferences
  • Flash brightness
  • AI detection sensitivity
  • Snapshot quality

App Preferences:

  • Dark/Light mode
  • Language
  • Notifications
  • Default view (Map/List)

API Configuration:

  • API keys for camera detection
  • Authentication tokens
  • Cloud services setup

Getting Help​

Built-In Tutorial​

From main menu:

  1. Tap "TUTORIAL" button
  2. Walkthrough shows:
    • Scanner controls
    • Filter modes
    • Detection features
    • Tips & tricks

First Time Tips​

Start with IR Scanner:

  1. Open app
  2. Tap "START SCAN"
  3. Point at suspicious areas
  4. Enable FLASH button
  5. Select RED or NV GREEN filter
  6. Look for bright reflections

Then Try Camera Detection:

  1. Return to main menu
  2. Tap "NEARBY CAMERAS"
  3. Wait for scan to complete
  4. View results on map or list

Finally Check Surveillance:

  1. Return to main menu
  2. Tap "DeFlock ALPR Map" (if licensed)
  3. View local surveillance camera coverage

Uninstallation​

If you need to uninstall ToadCAM:

  1. Long-press ToadCAM icon on home screen
  2. Tap "Uninstall"
  3. Confirm removal
  4. (Optional) Clear remaining cache:
    • Settings > Apps > ToadCAM > Storage > Clear Cache
