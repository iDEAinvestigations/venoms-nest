ToadCAM Tips, Best Practices & Troubleshooting

Best Practices for Camera Detection​

IR Scanner Optimal Conditions​

Best Detection Setup:

  • 🌙 Dim lights or turn off overhead lighting
  • 📱 Hold phone steady (use two hands)
  • 🔦 Use FLASH + RED filter combination
  • 🐢 Scan slowly and methodically
  • 🎯 Focus on each area (2-3 seconds)

Room Temperature:

  • IR works better in cooler rooms
  • Thermal differences help detection
  • Avoid scanning in direct sunlight
  • Evening/night ideal for detection

Phone Position:

  • Hold at ~45-degree angle
  • Move systematically across room
  • Don't skip areas
  • Rescan suspicious areas

Identifying False Positives​

These are NOT hidden cameras:

  • Reflective buttons and fasteners
  • Small holes in vents or grilles
  • Screw holes in furniture
  • Chrome or metallic trim
  • Phone charging ports
  • Decorative objects with holes

How to verify:

  1. Does it have a glass lens? (Look closely)
  2. Can you see camera components?
  3. Is there a visible lens element?
  4. Does it connect anywhere (wires)?

High-Success Scanning Technique​

  1. Prepare Room:

    • Dim lights
    • Close curtains
    • Turn off other screens
    • Clear clutter from scanning areas

  2. Set Up Scanner:

    • Enable FLASH (strobe on)
    • Select RED filter
    • Enable AI detection
    • Ensure good battery

  3. Systematic Scan:

    • Start at doorway
    • Scan left wall top to bottom
    • Move to next wall
    • Don't skip anywhere
    • Spend 10-15 minutes per room

  4. Focus Zones:

    • Smoke detectors (most common)
    • Light fixtures
    • Clocks and electronics
    • Decorative items
    • Air vents
    • Mirrors and glass

  5. Suspicious Findings:

    • Take snapshots
    • Note exact location
    • Measure distance from suspicious spot
    • Document everything
    • Don't touch or disassemble

Common Issues & Solutions​

Scanner Shows Mostly Dark Feed​

Causes:

  • Room too dark for camera
  • Phone camera infrared limited
  • Object too far away
  • Screen brightness too low

Solutions:

  • Turn on room lights
  • Move closer to suspected object
  • Adjust phone brightness
  • Try different filters (RED works in daylight)
  • Try NV GREEN filter for low-light

Flash Not Working​

Causes:

  • Flash already in use by other app
  • Phone storage full
  • Flash disabled in settings
  • Hardware failure

Solutions:

  1. Close all other apps
  2. Check available storage (need 500MB+)
  3. Restart phone
  4. Try scanner again
  5. If still not working, flash hardware may be broken

AI Detection Not Working​

Causes:

  • Not supported on older phones
  • Requires processing power
  • Phone too slow
  • Outdated app version

Solutions:

  1. Update ToadCAM to latest version
  2. Close other apps (free RAM)
  3. Restart phone
  4. Try in better lighting
  5. If still not working, phone may not support AI

Screen Keeps Rotating​

Causes:

  • Auto-rotate enabled
  • Device orientation sensor active
  • Holding phone at angles triggers rotation

Solutions:

  1. Go to Settings
  2. Find Display settings
  3. Toggle Auto-rotate OFF
  4. Return to scanner
  5. Screen should stay portrait/landscape

Scanner Freezes or Lags​

Causes:

  • Too many apps running
  • Phone low on RAM
  • Storage nearly full
  • Camera app conflict

Solutions:

  1. Close all background apps
  2. Restart phone completely
  3. Free up storage (delete old photos/videos)
  4. Uninstall unused apps
  5. Try scanner again after restart

Permission Errors​

Camera permission says "Denied":

  1. Go to Settings > Apps > ToadCAM
  2. Tap Permissions
  3. Tap Camera
  4. Select Allow
  5. Go back to ToadCAM and retry

Location permission not working:

  1. Open Settings > Location
  2. Ensure Location is ON
  3. Select High Accuracy mode
  4. Go to Apps > ToadCAM > Permissions
  5. Tap Location
  6. Select Allow all the time (not just while using app)

Nearby Cameras Troubleshooting​

Scan Takes Forever​

Causes:

  • Large home network (many devices)
  • Slow internet connection
  • API servers slow
  • WiFi interference

Solutions:

  1. Move closer to router
  2. Close other internet-using apps
  3. Try again at different time
  4. Check internet speed (speedtest.net)
  5. Ensure WiFi signal is strong

Finds Too Many Devices​

Causes:

  • Large network with many devices
  • Filters not applied
  • False positives from routers/printers
  • Smart home devices showing as cameras

Solutions:

  1. Use filters to narrow results
  2. Select "IP Cameras" filter for actual cameras
  3. Research unknown devices
  4. Unplug devices you don't recognize
  5. Check what you own vs. unknown devices

Finds No Local Cameras​

Reasons:

  • No cameras on your network
  • Cameras turned off
  • Cameras on different WiFi
  • Cameras not networked
  • Firewall blocking detection

What to do:

  1. Ensure your cameras are powered on
  2. Verify they're on same WiFi network
  3. Check router firewall isn't blocking
  4. Restart cameras
  5. Manually check if cameras accessible

API Errors​

"API Authentication Failed":

  1. Check API key is correct
  2. Verify API key still valid
  3. Ensure account has credits/quota
  4. Try again later (server issues)
  5. Reenter API key if copied wrong

"Rate Limited":

  1. Wait 15-30 minutes before retrying
  2. API quotas reset hourly/daily
  3. Check your API service plan
  4. Upgrade plan if exceeding limits
  5. Try manual scan in meantime

DeFlock ALPR Map Issues​

Map Won't Load​

Causes:

  • No internet connection
  • Location services disabled
  • Map API keys not configured
  • Server temporarily down

Solutions:

  1. Check internet connection
  2. Enable location services
  3. Wait a few minutes and retry
  4. Check settings for required API keys
  5. Restart ToadCAM

Markers in Wrong Location​

Causes:

  • GPS inaccuracy
  • Map data outdated
  • Coordinate system mismatch
  • Device location services imprecise

Solutions:

  1. Move outdoors for better GPS
  2. Enable high-accuracy mode in settings
  3. Wait for GPS to stabilize (2-3 minutes)
  4. Move 100+ feet away and come back
  5. Check phone's GPS accuracy (Settings > About > Location)

No Cameras Showing on Map​

Reasons:

  • Rural area (few cameras installed)
  • Cameras filtered out
  • Data not updated for your area
  • Internet connection lost

Solutions:

  1. Check filter settings (toggle layer icons)
  2. Ensure all camera types enabled
  3. Move to urban area to test
  4. Check internet connection
  5. Force refresh or restart app

General App Troubleshooting​

App Crashes on Launch​

Solutions:

  1. Restart phone
  2. Clear app cache: Settings > Apps > ToadCAM > Storage > Clear Cache
  3. Update ToadCAM to latest version
  4. Uninstall and reinstall app
  5. Check for Android OS updates

App Crashes During Scanning​

Causes:

  • Low memory/RAM
  • Storage full
  • Other apps consuming resources
  • Phone overheating

Solutions:

  1. Close all other apps
  2. Free up storage (delete old files)
  3. Restart phone
  4. Let phone cool down if warm
  5. Check available RAM (Settings > About)

License Won't Activate​

Solutions:

  1. Check internet connection
  2. Verify license key is correct (case-sensitive)
  3. Ensure you haven't used key on another device
  4. Try activating again in 5-10 minutes
  5. Contact support: sales@ideatech.us

License Expired​

What to do:

  1. Check expiration date in settings
  2. Contact Venom's Nest for renewal
  3. Request new license key
  4. Activate new key in settings
  5. App features will unlock

Performance Optimization​

Free Up Phone Resources​

  1. Close Background Apps:

    • Swipe recent apps closed
    • Kill unnecessary processes
    • Close instant messaging apps

  2. Free Storage Space:

    • Delete old photos/videos
    • Clear download folder
    • Remove unused apps
    • Clear browser cache

  3. Reduce System Load:

    • Disable auto-sync
    • Turn off notifications
    • Stop background updates
    • Disable other sensors

  4. Improve Network:

    • Move closer to router
    • Restart router
    • Check WiFi signal
    • Switch to 5GHz band if available

Battery Optimization​

  • Enable battery saver mode for long scanning sessions
  • Reduce screen brightness
  • Close apps running in background
  • Disable Bluetooth/NFC if not needed
  • Keep scanner session short if battery low

  • License won't activate after multiple tries

Safety Reminders​

Legal & Ethical Use​

✅ Appropriate Uses:

  • Scan your own property
  • Professional security assessment (with permission)
  • Hotel room security check
  • Home privacy audit
  • Workplace safety verification

❌ Illegal Uses:

  • Scanning others' property without consent
  • Using to plan crimes
  • Evading law enforcement
  • Stalking or harassment
  • Violation of privacy laws

Physical Safety​

  • Don't touch unknown devices
  • Preserve evidence if suspicious
  • Don't disassemble anything
  • Report to authorities
  • Avoid confrontation

Device Safety​

  • Keep phone updated
  • Use strong passwords/biometrics
  • Protect screenshots of findings
  • Avoid public WiFi for sensitive data
  • Back up important documentation
