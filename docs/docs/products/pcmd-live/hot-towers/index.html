Hot Towers & V-Strike Triangulation

These advanced features help identify frequently used locations and estimate precise device positions.

Hot Towers - Identifying Frequent Locations​

Purpose​

Identify the cell towers used most frequently by a device, revealing where the person spent most time.

Accessing Hot Towers​

From Results Screen:

  1. After analyzing PCMD file
  2. Tap "Hot Towers" tab
  3. List displays ranked by usage

Understanding Hot Towers​

What Hot Towers Show:

Towers ranked by usage (most hits first):

Each tower card displays:

InformationMeaning
Tower ID / Site NameUnique tower identifier
Total HitsNumber of records using tower
Percentage% of total activity
Sector BreakdownAlpha/Beta/Gamma usage
Distance StatsMin/Avg/Max distance in miles

Interpreting Results​

High-Hit Towers:

  • Indicate frequent presence areas
  • Multiple recordings suggest extended time there
  • Likely home, work, or frequent location
  • Concentrated activity = residential area

Sector Breakdown:

  • Alpha/Beta/Gamma = sectors of tower
  • Shows directional patterns
  • Multiple sectors = movement within area
  • Single sector = concentrated location

Distance Statistics:

  • Min Distance = Closest approach to tower
  • Avg Distance = Average distance
  • Max Distance = Farthest reach
  • Indicates area coverage

Using Hot Towers Results​

Identifying Home/Work:

  1. Review top 3-5 towers
  2. Note daily pattern towers
  3. High usage weekday morning = work area
  4. High usage evening/weekends = home area
  5. Consistent usage = regular location

Finding Frequent Locations:

  1. Look at top hit towers
  2. Check for geographic clusters
  3. Note seasonal variations if data spans months
  4. Tap tower to show on map

Actions​

Tap a Tower Card to:

  • Open location in Google Maps
  • See exact tower coordinates
  • View tower details
  • Understand geographic context
  • Export tower information

V-Strike Triangulation​

Purpose​

Estimate probable device location using multiple tower data points with triangulation algorithm.

How V-Strike Works​

The Calculation:

  1. Takes data from multiple towers (typically top towers)
  2. Calculates the centroid (center point) of all positions
  3. Weights by data confidence
  4. Computes confidence radius
  5. Displays as single estimated location

Why Triangulation Matters:

  • Single tower gives approximate area
  • Two towers narrow location better
  • Three+ towers enable triangulation
  • Provides more accurate estimate than single tower
  • Creates best possible location estimate

Accessing V-Strike​

From Results Screen:

  1. After analyzing PCMD file
  2. Tap "V-Strike" tab
  3. Estimated location displays on map

Understanding V-Strike Results​

V-Strike Display Shows:

FieldMeaning
Center CoordinatesLatitude/Longitude of estimate
Confidence RadiusEstimated error radius (miles)
Confidence LevelHIGH / MEDIUM / LOW
Contributing TowersWhich towers used in calculation
Visual Confidence PolygonShaded area on map

Confidence Levels​

HIGH Confidence (95%+):

  • Criteria: 10+ data points, tight spread (<0.5 mi)
  • Most accurate estimate
  • Probably accurate location
  • Use with confidence

MEDIUM Confidence (50-95%):

  • Criteria: 5+ data points OR spread <1.0 mi
  • Reasonably accurate
  • Use as starting point
  • Cross-verify with other evidence

LOW Confidence (Below 50%):

  • Criteria: Limited data or wide spread
  • Less certain location
  • Use for general area only
  • Verify through other means

Confidence Factors​

Increases Confidence:

  • More data points (more calls/sessions)
  • Tighter geographic spread
  • More towers involved
  • Urban area (better tower coverage)
  • Recent data

Decreases Confidence:

  • Few data points
  • Wide geographic spread
  • Rural area (sparse towers)
  • Old data
  • Mixed carrier data

Using V-Strike Results​

Reading the Map​

Visual Representation:

  • 📍 Center point = Most likely location
  • 🟣 Shaded circle = Confidence radius
  • 📌 Contributing tower markers shown
  • 🗺️ Map controls for zoom/pan

Interpreting Accuracy​

Typical Accuracy Ranges:

Area TypeAccuracyFactors
Urban100-500 feetDense towers
Suburban500-2000 feetModerate coverage
Rural0.5-2 milesSparse towers

Radius Shows Uncertainty:

  • Larger radius = Less certain location
  • Smaller radius = More confident
  • Always consider full radius
  • Actual location within radius

Comparing Multiple Triangulations​

If you have data from multiple time periods:

  1. Run V-Strike for each period
  2. Note center coordinates
  3. Compare positions
  4. Look for patterns
  5. Identify movement

Practical Applications​

Identifying Likely Locations​

Use V-Strike to estimate:

  • Home location (if data spans evenings/weekends)
  • Work location (if data spans weekday daytime)
  • Frequent meeting places
  • Travel routes
  • Anomalous locations

Verifying Alibis​

Check if person could have been at:

  • Claimed location
  • Crime scene
  • Important location
  • Timeline consistency

Method:

  1. Run V-Strike for claimed time period
  2. Compare to actual claimed location
  3. Consider radius/uncertainty
  4. Check if location possible

Timeline Creation​

Create movement timeline:

  1. Split data by date/time
  2. Run V-Strike for each period
  3. Note location changes
  4. Document movements
  5. Create visual timeline

Advanced Analysis​

Multi-Carrier Analysis​

If analyzing multiple carriers:

  1. Analyze Verizon PCMD first
  2. Note V-Strike results
  3. Analyze AT&T data
  4. Compare triangulations
  5. Strongest result usually most accurate

Cross-Validation​

Verify triangulation accuracy:

  1. Run V-Strike
  2. Check with Hot Towers
  3. Compare to known addresses
  4. Use Live Ping data if available
  5. Cross-reference with GPS data

Understanding Limitations​

Why V-Strike May Be Inaccurate​

Tower Density Issues:

  • Sparse tower coverage = wider radius
  • Urban areas more accurate
  • Rural areas less accurate
  • Single operator data incomplete

Data Quality Issues:

  • RSSI inaccuracy
  • Signal anomalies
  • Equipment malfunctions
  • Data transmission errors

Methodology Limitations:

  • Triangulation assumes line-of-sight
  • Actual signals reflect and scatter
  • Buildings block signals
  • Terrain affects propagation

Device Limitations:

  • Phone switches towers for better signal
  • Multi-tower connections not shown
  • Handoffs not captured
  • Transitions smoothed over

Never 100% Accurate​

Remember:

  • ⚠️ V-Strike gives estimate, not exact location
  • ⚠️ Always consider confidence radius
  • ⚠️ Use multiple verification methods
  • ⚠️ Don't rely solely on PCMD triangulation
  • ⚠️ Cross-reference with other evidence

Best Practices​

Documentation​

When using V-Strike results:

  1. Document exact coordinates
  2. Note confidence level
  3. Record confidence radius
  4. Screenshot results
  5. Save in report

Verification​

Always verify triangulation:

  1. Check with Hot Towers analysis
  2. Compare with independent GPS data
  3. Validate against known locations
  4. Consider physical constraints
  5. Cross-reference multiple sources

Legal Considerations​

  • Use results appropriately
  • Document methodology
  • Consider limitations
  • Present with uncertainty
  • Include disclaimer about accuracy
