Live Ping Tracking & Saved Addresses

These features enable real-time location tracking and address management for overlap detection.

Live Ping Tracking​

Purpose​

Process real-time carrier ping locations to track active device positions.

Accessing Live Ping​

From Home Screen:

  1. Tap "Live Ping" button
  2. Two methods available:
    • Paste ping data directly
    • Connect email for automatic sync

Method 1: Direct Ping Paste​

Step-by-Step:

  1. Obtain Ping Data:

    • Get ping text from email/message
    • Obtain from authorized carrier
    • Copy the entire ping response

  2. Paste Into App:

    • Tap in the text input area
    • Paste the ping data
    • Carrier auto-detects as you type

  3. Process Ping:

    • Tap "Process Ping" button
    • Wait for processing
    • Result displays on map

Supported Ping Formats​

Verizon Format:

Location of 7812153264 at 8/2/2018 4:14:16 PM === Result ===
Lat, Long: 42.501962,-70.931833 Uncertainty: 1881m

AT&T Format:

LAT: 42.3601 LONG: -71.0589 RADIUS: 500m

T-Mobile Format:

Latitude: 42.3601, Longitude: -71.0589, Accuracy: 250 meters

Method 2: Email Integration​

For Gmail Users:

  1. Connect Gmail Account:

    • Tap "Email" tab in Live Ping screen
    • Tap "Connect Gmail"
    • Sign in with your Gmail account
    • Grant permission to read emails

  2. Sync Pings:

    • Tap "Sync Pings" button
    • App scans email for ping responses
    • Detected pings automatically imported
    • Results appear on map

  3. Automatic Imports:

    • Look for emails from carrier
    • Subject lines containing location data
    • Ping responses in email body
    • Auto-parse and display

Live Ping Map View​

Map Display Shows:

ElementMeaning
Green circleSelected ping with uncertainty radius
Red circlesOther pings from same tracking
CoordinatesPrecise latitude/longitude
TimestampDate and time of ping
Uncertainty RadiusMargin of error (in meters)

Map Controls:

  • Tap any ping marker to select it
  • Info card shows details
  • Pinch to zoom in/out
  • Drag to pan around map

Proximity Alerts​

When Ping Matches Saved Address:

  • Alert dialog appears
  • Shows matching tower/location
  • Displays address name
  • Helps correlate live location with historical data

Matching Criteria:

  • Ping within saved address radius
  • Automatic notification
  • Shows address details
  • Enables quick identification

Address Overlap Detection​

Live Ping vs Saved Addresses:

  1. Toggle address layer with pin icon button
  2. Orange markers show saved addresses
  3. If ping overlaps saved address:
    • Orange notification card appears
    • Shows address name
    • Displays distance from ping

Saved Addresses - Location Bookmarks​

Purpose​

Save locations of interest for automatic overlap detection with PCMD and Live Ping data.

Accessing Saved Addresses​

From Home Screen:

  1. Tap "Saved Addresses" button
  2. View list of saved addresses
  3. Add, edit, or delete addresses

Adding a New Address​

Step-by-Step:

  1. Tap "+" floating button

  2. Fill in the form:

    • Name: Descriptive label
      • Examples: "Home", "Work", "Suspect Location", "Crime Scene"
    • Street Address: Full address for reference
    • Latitude: Decimal degrees (e.g., 42.3601)
    • Longitude: Decimal degrees (e.g., -71.0589)
    • Notes: Optional additional information

  3. Tap "Save"

  4. Address added to list

Editing an Address​

To Modify:

  1. Find the address in the list
  2. Tap pencil (edit) icon on card
  3. Modify fields as needed
  4. Tap "Save"
  5. Changes applied immediately

Deleting an Address​

To Remove:

  1. Find address in list
  2. Tap trash (delete) icon
  3. Confirm deletion in dialog
  4. Address removed from list

Getting Coordinates​

Find Latitude/Longitude:

Method 1 - Google Maps:

  1. Open Google Maps
  2. Search for location
  3. Tap location
  4. Long-press on map
  5. Coordinates shown at bottom
  6. Copy and paste into app

Method 2 - Manual Entry:

  1. Remember latitude/longitude format
  2. Latitude: N/S degrees (-90 to +90)
  3. Longitude: E/W degrees (-180 to +180)
  4. Example: 42.3601, -71.0589

Method 3 - From Map in App:

  • Many features show coordinates
  • Copy from map display
  • Paste into address form

Understanding Overlap Detection​

How It Works:

  1. When PCMD data is loaded:

    • App checks all device positions
    • Calculates distance to each saved address
    • Auto-radius based on data accuracy (0.1 to 2 miles)

  2. Addresses within radius flagged as "overlapping"

  3. Results displayed on map with highlights

Viewing Overlaps - Results Map​

On Results Map:

  • Address filter chip shows overlap count
  • Overlapping addresses highlighted orange
  • Marker shows "OVERLAP - X.XX mi" in popup
  • Tap to see details

Viewing Overlaps - Live Ping​

During Live Ping Tracking:

  • Orange notification card when ping matches address
  • Shows address name
  • Displays distance from ping
  • Helps identify when at saved location

Address List Management​

Organizing Addresses:

  • Name addresses descriptively
  • Group by type (Home, Work, Location of Interest)
  • Add notes for context
  • Update as needed

Example Address Setup:

  • "Home" - Residential address
  • "Work" - Business address
  • "Suspect Residence" - Investigation target
  • "Crime Scene" - Location of interest
  • "Meeting Point A" - Significant location

Practical Applications​

Investigation Setup​

Before analyzing PCMD:

  1. Save all known locations:

    • Suspect home
    • Suspect work
    • Crime scene
    • Other locations of interest

  2. Analyze PCMD file

  3. Check for overlaps automatically

  4. Review results on map

Timeline Creation​

Using Both Features:

  1. Analyze historical PCMD (Hot Towers/V-Strike)
  2. Save key locations
  3. Note overlaps
  4. Process Live Ping data
  5. Compare live to historical
  6. Create comprehensive timeline

Location Verification​

Verify Claims:

  1. Person claims to be at Location A
  2. Save Location A as address
  3. Analyze PCMD for that timeframe
  4. Check for overlap
  5. If overlap exists, claim may be true
  6. If no overlap, claim likely false

Proximity Analysis​

Find Relationships:

  1. Save multiple suspect locations
  2. Analyze PCMD
  3. Check overlaps
  4. Multiple overlaps suggest connection
  5. Note timing of overlaps
  6. Create pattern analysis

Best Practices​

Data Accuracy​

For Accurate Results:

  • Use precise coordinates from Google Maps
  • Verify addresses before saving
  • Update coordinates if locations change
  • Note margin of error (up to 2 miles)
  • Cross-reference with independent data

Security & Privacy​

  • Protect saved addresses
  • Don't share device with sensitive data
  • Use secure location for saved files
  • Delete addresses after case closed
  • Follow privacy laws in your jurisdiction

Documentation​

When Using These Features:

  1. Document all saved addresses
  2. Record coordinates used
  3. Screenshot overlap results
  4. Note timestamps of pings
  5. Save analysis results

Verification​

Always Verify:

  1. Overlaps alone don't prove presence
  2. Cross-reference with other evidence
  3. Consider data accuracy (large radius)
  4. Use multiple sources
  5. Don't rely solely on PCMD

Limitations & Considerations​

Accuracy Constraints​

  • Addresses have uncertainty radius
  • PCMD accuracy varies (0.1-2 miles)
  • Rural areas less accurate
  • Only shows tower connection, not exact location
  • Phone may be elsewhere within tower range

Data Limitations​

  • Only available for analyzed phones
  • Requires authorized PCMD access
  • Historical data only (not real-time until Live Ping)
  • May not include all carriers
  • Gaps in coverage possible

Legal Considerations​

  • Ensure proper authorization
  • Follow applicable laws
  • Obtain proper warrants if required
  • Document legal basis
  • Preserve chain of custody

Troubleshooting​

Overlap Not Detecting​

Even though should overlap:

Possible causes:

  • Address coordinates too precise
  • PCMD data sparse in area
  • Outside auto-radius (>2 miles)
  • Carrier data incomplete

Solutions:

  1. Verify address coordinates
  2. Check PCMD data for that area
  3. Manually review map
  4. Consider expanding radius
  5. Use V-Strike for estimates

Live Ping Won't Process​

Ping data rejected or error:

Causes:

  • Wrong format pasted
  • Incomplete ping response
  • Carrier not recognized
  • Malformed data

Solutions:

  1. Verify ping format correct for carrier
  2. Paste entire response, not partial
  3. Check carrier is supported
  4. Try manual entry of coordinates
  5. Copy directly from source

Email Sync Not Working​

Gmail pings not syncing:

Possible reasons:

  • Gmail not connected
  • Permission not granted
  • No ping emails present
  • Account connection expired

Solutions:

  1. Disconnect and reconnect Gmail
  2. Grant required permissions again
  3. Check email has ping messages
  4. Refresh/retry sync
  5. Try manual paste method
