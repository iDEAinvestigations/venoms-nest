PCMD Live Troubleshooting & Best Practices

Common Issues & Solutions​

License & Installation Issues​

"License activation failed" error:

Solutions:

  1. Check internet connection is active
  2. Verify license key is correct
  3. Ensure you entered full key (no spaces)
  4. Try activating again after few minutes
  5. Server may be temporarily busy

"License already used on another device":

Each license tied to one device only.

Solutions:

  1. Contact support: sales@ideatech.us
  2. Provide your license key
  3. Request device binding reset
  4. Support will reset it
  5. You can then activate on new device

License Expiration:

What to do:

  1. Contact support for renewal
  2. Request new license key
  3. Note your license tier
  4. Activate new key in app
  5. All features immediately available

File Upload & Analysis Issues​

"File not found" when selecting:

Causes:

  • File deleted or moved
  • Path changed
  • File in restricted folder
  • Storage permission denied

Solutions:

  1. Copy file to Downloads folder
  2. Try selecting from Downloads
  3. Grant storage permission
  4. Check file location exists
  5. Rename if filename has special characters

"File format not recognized":

Causes:

  • Wrong file type for carrier
  • File corrupted
  • File naming mismatch
  • Wrong spreadsheet format

Solutions:

  1. Verify correct carrier selected
  2. Check file format:
    • Verizon: .xlsx
    • AT&T: .txt or .csv
    • T-Mobile: .xlsx or .csv
  3. Try opening in spreadsheet app to verify
  4. Redownload from carrier if corrupted
  5. Check file isn't password protected

"Processing never completes" - stuck:

Causes:

  • Very large file (millions of records)
  • Slow phone processor
  • Low RAM available
  • Network interrupted

Solutions:

  1. Force stop and restart app
  2. Close all other apps
  3. Restart phone
  4. Free up storage space
  5. Try smaller file portion first
  6. Use newer/faster device if available

"Wrong results" or "Incorrect data":

Check:

  1. Correct carrier selected?
  2. Correct file for that carrier?
  3. Correct phone number in file?
  4. Date range correct?
  5. PCMD from reliable source?

Map & Results Issues​

Map won't load or shows blank:

Causes:

  • Location services disabled
  • GPS not locked
  • Internet connection lost
  • Map API error

Solutions:

  1. Enable Location Services:
    • Settings > Location > Toggle ON
    • Select "High Accuracy" mode
  2. Check Internet: WiFi or cellular active
  3. Restart App: Close and reopen
  4. Move Outdoors: Better GPS lock
  5. Wait for GPS: May take 30+ seconds

Map shows wrong coordinates:

Reasons:

  • GPS inaccuracy
  • PCMD data unusual tower configuration
  • Coordinate system mismatch

What to do:

  1. Enable high-accuracy location mode
  2. Compare with known locations
  3. Consider tower density in area
  4. Cross-reference with V-Strike
  5. May be system limitation

Saved addresses not showing overlaps:

Causes:

  • Address coordinates incorrect
  • PCMD data sparse at address
  • Address outside auto-radius (>2 miles)
  • Layer filter turned off

Solutions:

  1. Verify address coordinates in Google Maps
  2. Manually compare on map
  3. Check if data covers that area
  4. Toggle address layer ON
  5. Consider manual review if overlaps unclear

Hot Towers & Triangulation Issues​

Hot Towers showing no data:

Causes:

  • PCMD file empty
  • Wrong carrier selected
  • File parsing error

Solutions:

  1. Reload PCMD file
  2. Verify carrier is correct
  3. Try different file
  4. Check file has valid records

V-Strike showing zero confidence:

Reasons:

  • Insufficient data points
  • Very sparse tower coverage
  • Rural area with few towers
  • Data too dispersed

What to do:

  1. This is normal in rural areas
  2. Review Hot Towers as alternative
  3. Use timeline view for patterns
  4. Cross-reference with other evidence
  5. Consider other analysis methods

V-Strike coordinates seem wrong:

Possible causes:

  • Low confidence (wide radius)
  • Data unusual distribution
  • Device was mobile (not stationary)
  • Tower density issues

Remember:

  • ⚠️ V-Strike gives estimate, not exact location
  • ⚠️ Always consider confidence radius
  • ⚠️ Don't rely solely on triangulation
  • ⚠️ Cross-verify with other evidence

Live Ping Issues​

"Ping not processing" error:

Causes:

  • Wrong format
  • Incomplete data
  • Carrier not recognized
  • Malformed coordinates

Solutions:

  1. Verify ping format correct for carrier
  2. Ensure complete ping response pasted
  3. Check carrier is supported (Verizon/AT&T/T-Mobile)
  4. Try manually entering coordinates
  5. Paste directly from source email

Gmail sync not working:

Causes:

  • Gmail not connected
  • Permission not granted
  • No ping emails present
  • Token expired

Solutions:

  1. Reconnect Gmail:
    • Tap "Email" tab
    • Disconnect current account
    • Tap "Connect Gmail"
    • Sign in again
  2. Grant Permissions: Allow email read access
  3. Verify Emails: Check Gmail has ping messages
  4. Retry Sync: Tap "Sync Pings" again

Coordinates seem inaccurate:

Reasons:

  • Ping uncertainty radius large
  • Device actually far from tower
  • Carrier ping system limitations
  • Reported coordinates approximation

Remember:

  • Ping includes uncertainty radius
  • Trust the radius, not point estimate
  • Don't assume exact location
  • Consider movement within radius

Performance Issues​

App Running Slow:

Causes:

  • Too much data loaded
  • Other apps using resources
  • Low RAM available
  • Device overheating

Solutions:

  1. Close other apps
  2. Restart phone
  3. Reduce map zoom (less data rendering)
  4. Delete old analysis results
  5. Free up storage space

Phone Overheating:

During Analysis:

  • Large file processing is CPU intensive
  • Generates heat
  • Let phone cool naturally
  • Pause processing if too hot
  • Restart in cooler environment

What to do:

  1. Close app
  2. Let phone cool down (1-2 hours)
  3. Restart in cooler location
  4. Use near air conditioning
  5. Remove case if metal
  6. Retry analysis

Battery Drains Quickly:

Reasons:

  • GPS constantly active
  • Map rendering
  • Large file processing
  • WiFi/cellular active

Solutions:

  1. Close app when not using
  2. Disable WiFi/cellular if not needed
  3. Reduce screen brightness
  4. Use battery saver mode
  5. Close other apps

Best Practices​

Working with PCMD Files​

Before Analysis:

  1. Verify Source:

    • Legitimate carrier source?
    • Proper authorization obtained?
    • Chain of custody maintained?

  2. Check Integrity:

    • File not corrupted?
    • All expected data present?
    • Date range reasonable?
    • Phone number correct?

Using Analysis Results​

Document Everything:

  1. Record Methods:

    • Which PCMD file analyzed
    • Carrier and date range
    • Phone number target
    • Analysis tools used

  2. Screenshot Results:

    • Map views
    • Hot Towers list
    • V-Strike triangulation
    • Timeline views

  3. Note Findings:

    • Key locations identified
    • Frequent areas
    • Movement patterns
    • Anomalies noticed

Accuracy Considerations​

Remember Limitations:

  • PCMD shows tower connection, not exact location
  • Urban areas more accurate
  • Rural areas less accurate
  • Triangulation provides estimate
  • Confidence radius shows uncertainty
  • Always cross-verify

Legal & Ethical Use​

Proper Authorization:

  • Ensure legal right to access data
  • Obtain proper warrants if required
  • Follow all privacy laws
  • Document authorization
  • Maintain confidentiality

Professional Standards:

  • Document all methods
  • Disclose limitations
  • Present with uncertainty
  • Don't overstate accuracy
  • Include error margins

Advanced Troubleshooting​

Clear App Cache​

If app acting strange:

  1. Go to Settings > Apps > PCMD Live
  2. Tap "Storage"
  3. Tap "Clear Cache"
  4. Restart app
  5. Don't lose saved data

Factory Reset​

Last resort option:

  1. Go to Settings > Apps > PCMD Live
  2. Tap "Storage"
  3. Tap "Clear Data" (⚠️ Deletes all app data)
  4. Uninstall app
  5. Restart phone
  6. Reinstall PCMD Live
  7. Reactivate license
