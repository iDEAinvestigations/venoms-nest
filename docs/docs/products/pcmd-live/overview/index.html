PCMD Live - Call Detail Record Analysis & Triangulation Tool

PCMD Live is a specialized tool for analyzing wireless carrier call detail records (PCMD - "Position Connection Management Data") and performing triangulation analysis to determine device locations based on cellular tower connections.

Core Features​

PCMD File Analysis​

  • Multi-Carrier Support: Verizon, AT&T, T-Mobile
  • Call Detail Parsing: Extract tower connections from records
  • Date/Time Analysis: Filter by time period
  • Number Pattern Analysis: Identify calling patterns
  • Duration Metrics: Call length analysis

Hot Tower Identification​

  • Tower Clustering: Identify frequently used towers
  • Geographic Hotspots: Pinpoint locations device frequent
  • Pattern Recognition: Track movement patterns
  • Temporal Analysis: Time-based tower usage
  • Confidence Scoring: Reliability of location data

V-Strike Triangulation​

  • Multi-Tower Analysis: Use 3+ towers for accuracy
  • Triangulation Calculation: Pinpoint location between towers
  • Margin of Error: Confidence radius display
  • Map Integration: Visualize results on map
  • Timeline View: Track movement over time

Live Ping Tracking​

  • Real-Time Tracking: Track active devices
  • GPS Integration: Compare with actual GPS data
  • Accuracy Comparison: Tower vs GPS location
  • Movement Alerts: Notify when device moves
  • Historical Comparison: Compare to historical CDR data

System Requirements​

  • Android 8.0 or higher
  • Carrier-provided PCMD files (Excel, CSV, or text)
  • Valid PCMD Live license key
  • 150MB+ free storage
  • Location services for mapping

Data Types​

What PCMD Shows​

Each call detail record typically contains:

  • Phone Number: Called/calling number
  • Tower ID: Cell tower used for connection
  • Tower Location: Tower coordinates
  • Date/Time: When connection occurred
  • Duration: Length of call/data session
  • Direction: Incoming/outgoing
  • Data Volume: For data sessions

Location Accuracy​

  • Single Tower: Approximate location (tower coverage area)
  • Two Towers: Better approximation (narrowed area)
  • Three Towers: Triangulation (most accurate)
  • Typical Accuracy: 100-1000 feet in urban areas

Use Cases​

  • Law Enforcement: Device location analysis for investigations
  • Private Investigation: Locate persons of interest
  • Corporate Security: Employee location verification
  • Fraud Investigation: Verify claimed locations
  • Civil Litigation: Location evidence for lawsuits
  • Insurance Claims: Verify claim circumstances

Data Sources​

Obtaining PCMD Files​

PCMD files are obtained from:

  • Law Enforcement: Law enforcement agencies can request from carriers (subpoena)
  • Legal Discovery: Civil cases (court order required)
  • Authorized Access: Carriers provide to authorized personnel
  • Voluntary Records: Individuals can request their own records

Note: PCMD files should only be obtained and analyzed with proper legal authorization.

Legal Considerations​

Proper Authorization Required​

PCMD analysis should only be conducted:

  • ✅ By law enforcement with proper authority
  • ✅ In civil cases with court order
  • ✅ By individuals analyzing their own records
  • ✅ By authorized corporate security professionals

Unauthorized Access is Illegal​

❌ Unauthorized access to CDR data is illegal ❌ Tracking without consent violates wiretapping laws ❌ Privacy violations can result in criminal charges

warning

Users are solely responsible for ensuring they have proper legal authorization to analyze PCMD data. Unauthorized tracking or surveillance is illegal.

Key Limitations​

  • Accuracy: Tower location is approximate (±100-1000 feet)
  • Frequency: Only shows when device made calls/data connections
  • Real-Time: Analysis is post-event (historical data)
  • Coverage Gaps: Doesn't show when device in no-coverage area
  • Roaming: Accuracy varies with roaming between carriers
