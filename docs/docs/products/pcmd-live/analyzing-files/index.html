Analyzing PCMD Files - Call Detail Record Processing

PCMD (Position Connection Management Data) analysis is the core feature of PCMD Live. This guide shows how to upload and analyze carrier call detail records.

Understanding PCMD Data​

What is PCMD?​

PCMD = Position Connection Management Data

Call Detail Records that include:

  • Phone number
  • Tower used for connection
  • Tower coordinates (latitude/longitude)
  • Date and time of connection
  • Call duration (for calls)
  • Data volume (for data sessions)
  • Connection direction (in/outbound)

Why PCMD Matters​

PCMD data enables:

  • Location Tracking: See where phone was when connected to towers
  • Tower Analysis: Identify frequently used locations
  • Triangulation: Estimate precise location using multiple towers
  • Pattern Recognition: Understand movement and behavior patterns
  • Timeline Creation: Create activity timeline from records

Supported Carriers​

CarrierFile FormatFile Type
VerizonExcel.xlsx
AT&TText/CSV.txt, .csv
T-MobileExcel.xlsx, .csv

Getting PCMD Files​

How to Obtain Files​

Legal Methods:

  • Direct from carrier (if authorized)
  • Law enforcement requests (with warrant)
  • Court-ordered discovery
  • Legal compliance investigations

File Types​

Verizon Files:

  • VoLTE_Call_Detail*.xlsx
  • RTT_Detail*.xlsx (Real-Time Transfer)
  • Historical_Call_Detail*.xlsx
  • IP_Data_Session*.xlsx

AT&T Files:

  • ReportLoc_*.txt (NELOS format)
  • Any tab/comma delimited location file

T-Mobile Files:

  • Timing Advance Excel files
  • CDR Excel files
  • Data Session Excel files

Analyzing PCMD Files​

Step 1: Select Carrier​

From Home Screen:

  1. Tap "Analysis" button
  2. Choose your carrier:
    • 🔵 VERIZON (blue) - For Verizon PCMD files
    • 🟦 AT&T (cyan) - For AT&T NELOS files
    • 🟥 T-MOBILE (pink) - For T-Mobile records

Step 2: Upload Data File​

After selecting carrier:

  1. Tap "Select PCMD File" or use drag/drop area
  2. Navigate to your PCMD file location
  3. Select the file:
    • Verizon: .xlsx files
    • AT&T: .txt or .csv files
    • T-Mobile: .xlsx or .csv files
  4. Confirm selection
  5. Wait for processing (progress indicator shows)

File Processing:

  • Status bar shows upload progress
  • May take 30 seconds to several minutes
  • Depends on file size and device speed
  • Keep app open during processing

Step 3: Review Results​

After successful parsing:

Results Screen Shows:

  • ✅ Record count (total entries)
  • ✅ Date range (earliest to latest)
  • ✅ Phone number analyzed
  • ✅ Processing status

View Results:

  • Tap "View Results" button
  • Results display on map with visualization
  • Multiple tabs available for analysis

Results Display & Maps​

Map View (Default)​

Interactive Google Map showing all data points:

Layer Toggle Controls (Filter Chips):

  • Towers - Show/hide tower markers
  • Sectors - Show/hide sector coverage polygons
  • Devices - Show/hide device position markers
  • Addresses - Show/hide saved address markers

Toggling Layers:

  1. Tap a filter chip to toggle on/off
  2. Active layers are highlighted
  3. Address chip shows overlap count badge
  4. Toggle multiple layers for complex views

Map Markers​

Tower Markers:

  • 🔴 RED pins = Tower locations
  • Shows tower location, ID, name
  • Tap for tower details

Device Position Markers:

  • 🟢 GREEN circles = Inbound calls
  • 🔵 BLUE circles = Outbound calls
  • 🟣 PURPLE circles = Voicemail
  • Size indicates RSSI/signal strength

Address Markers:

  • 🟠 ORANGE circles = Address overlaps
  • Indicates saved addresses within data range
  • Shows overlap count

Map Gestures​

Statistics Card​

Displays summary information:

  • Total Records: Number of call/data entries
  • Tower Count: Unique towers used
  • Date Range: From earliest to latest
  • Device Activity: Summary statistics
  • Samsung Exclusion Warning: If applicable

Understanding Data Points​

What Each Data Point Shows​

Each marker on map represents:

InformationMeaning
LocationWhere tower was located
Time/DateWhen connection occurred
Tower IDUnique tower identifier
RSSISignal strength at that time
DirectionCall in/out or data session
DurationLength of call or session

Signal Strength (RSSI)​

RSSI (Received Signal Strength Indicator) -40 to -140 dBm:

RSSIMeaningAccuracy
-40 to -80 dBmVery strong signalGood accuracy
-80 to -100 dBmGood signalModerate accuracy
-100 to -120 dBmFair signalLower accuracy
-120 to -140 dBmWeak signalPoor accuracy

Location Accuracy​

Single Tower:

  • Approximate location (tower coverage area)
  • Can be 1-5 miles radius
  • Used for general area

Two Towers:

  • Better approximation (narrowed area)
  • Can be 0.5-2 miles
  • More precise estimate

Three Towers (Triangulation):

  • Most accurate method
  • Can be 100-1000 feet in urban areas
  • Best for precise location

Analysis Tools​

Timeline View​

See chronological activity:

  1. Tap "Timeline" tab
  2. Activity displayed chronologically
  3. Shows each connection in order
  4. Click any entry to see on map

Date/Time Filtering​

Focus on specific time period:

  1. Tap "Date Range" filter
  2. Select start date
  3. Select end date
  4. Map updates to show only those dates

Export Functions​

Save analysis results:

  1. Tap "Export" button
  2. Choose format:
    • PDF report
    • CSV spreadsheet
    • Image snapshot
  3. Save to device storage
  4. Share via email/messaging

Working with Multiple Files​

Analyzing Different Carriers​

To analyze from different carriers:

  1. Go back to Analysis screen
  2. Select different carrier
  3. Upload new file
  4. Previous analysis saved automatically

Comparing Carriers​

Some scenarios involve multiple carriers:

  1. Analyze Verizon file first
  2. Note results and towers
  3. Go back to Analysis
  4. Select AT&T
  5. Upload AT&T file
  6. Compare results

Merging Data (Advanced)​

For comprehensive analysis:

  1. Analyze all available files separately
  2. Take notes/screenshots of results
  3. Document tower locations
  4. Note overlapping areas
  5. Cross-reference for accuracy

Common Issues​

File Won't Load​

Possible causes:

  • Wrong file format for carrier
  • File corrupted or incomplete
  • Storage permission not granted
  • File in unsupported location

Solutions:

  1. Verify file format matches carrier
  2. Ensure file not corrupted (try opening in spreadsheet app)
  3. Grant storage permission
  4. Copy file to Downloads folder
  5. Try again

File Processing Too Slow​

Reasons:

  • Large file (many records)
  • Slow phone processor
  • Low available RAM
  • Other apps running

Solutions:

  1. Close other apps
  2. Restart phone
  3. Free up RAM memory
  4. Try smaller file portion
  5. Use newer/faster device

Map Not Showing Data​

Possible causes:

  • Location services disabled
  • Map API not responding
  • GPS not locked
  • Internet not connected

Solutions:

  1. Enable location services
  2. Check internet connection
  3. Move outdoors for GPS lock
  4. Restart app
  5. Try again later

Incorrect Results​

Why results might be wrong:

  • Wrong phone number analyzed
  • Data from different time period
  • Incorrect carrier selection
  • File contains mixed data
  • RSSI inaccuracy

What to do:

  1. Verify correct file selected
  2. Check phone number in file
  3. Confirm carrier matches file type
  4. Review date range
  5. Cross-reference with V-Strike

Best Practices​

Data Verification​

Before using results:

  1. Verify file came from legitimate source
  2. Confirm correct phone number
  3. Check date range matches investigation period
  4. Cross-reference with other evidence
  5. Document all findings

Security & Privacy​

  • Don't share raw PCMD files
  • Protect analyzed data
  • Limit access to results
  • Delete sensitive files after analysis
  • Follow all privacy/legal requirements

Accuracy Considerations​

Remember:

  • PCMD shows tower connections, not exact location
  • Accuracy varies by tower density
  • Urban areas more accurate
  • Rural areas less accurate
  • Results are approximate
