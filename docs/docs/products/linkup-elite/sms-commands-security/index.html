Link Up Elite - SMS Commands & Security

SMS Command Security (v2.1)​

The SMS Command Security feature adds an extra layer of protection to prevent unauthorized control of the app via SMS commands.

Purpose​

Protect your Link Up Elite from unauthorized SMS control by requiring a secret PIN prefix on all commands from your Controller.

Location​

Access security settings in: Settings > Emergency Contacts > SMS Command Security

Command PIN Prefix​

What It Does​

Sets a secret PIN that must be included at the start of every SMS command. Without the correct PIN, commands are ignored.

Setting Up PIN​

  1. Open Link Up Elite
  2. Enter your PIN to access Settings
  3. Go to Emergency Contacts
  4. Scroll down to "SMS Command Security"
  5. Tap "Command PIN Prefix"
  6. Enter your desired PIN (4+ digits)
  7. Confirm the PIN
  8. Save settings

Using PIN-Protected Commands​

Example: If your PIN is "1234"

1234 STATUS           → Get app status (MUST include PIN)
1234 START            → Start streaming
1234 LOCATION         → Get GPS coordinates
1234 STOP             → Stop streaming

Without PIN prefix:

STATUS                → Ignored if PIN is set
START                 → Ignored if PIN is set

PIN Selection Tips​

  • Make it memorable: Don't forget your own PIN
  • Make it unique: Avoid obvious sequences (1234, 0000, 1111)
  • Share carefully: Only give PIN to trusted Controller
  • Change periodically: Update PIN every 6-12 months
  • Length: 4+ digits recommended

PIN Security Best Practices​

  1. Don't use:

    • Your phone number
    • Your birthday
    • Sequential numbers (1234, 4321)
    • Repeated numbers (1111, 2222)

  2. Do use:

    • Random combination (7392, 5618)
    • Mix of digits
    • Something you can remember
    • Something Controller doesn't know

Forgot Your PIN?​

If you forget your PIN:

  1. Contact support@ideatech.us
  2. Provide your license key proof
  3. Support can reset PIN (may require verification)
  4. Cannot reset without proof of ownership

Auto-Delete Commands​

What It Does​

Automatically deletes SMS commands from Controller after they're processed. This keeps the command history invisible in your messaging app.

How It Works​

  1. Controller sends SMS command
  2. Link Up Elite processes the command
  3. Command executed (e.g., streaming starts)
  4. SMS is automatically deleted (1-2 seconds later)
  5. Response message still sent back to Controller

Configuration​

  1. Go to Settings > Emergency Contacts
  2. Scroll to "SMS Command Security"
  3. Find "Auto-Delete Commands"
  4. Toggle ON to enable (recommended)
  5. Toggle OFF to disable
  6. Save changes

Requirements for Auto-Delete​

  • Link Up Elite must have full SMS permissions granted
  • SMS permission must be granted specifically for reading/deleting
  • Android 8.0 or higher
  • Works best with default SMS app

When Auto-Delete Might Fail​

  • Another SMS app is default: Link Up Elite can't delete from another app's inbox
  • Permissions not granted: Go to Settings > Apps > Link Up Elite > SMS permissions
  • Older Android version: Some versions don't support auto-delete reliably

Privacy Benefits​

  • Invisible command history: Snooping won't find instructions
  • No evidence of control: Commands don't appear in messaging app
  • Plausible deniability: No SMS trail in conversations
  • Response messages only: Controller's responses still visible (secure them!)

Recommended Settings​

✓ Recommended: Auto-Delete ON + PIN enabled

  • Maximum privacy and security
  • Commands invisible even if phone accessed
  • PIN prevents unauthorized use

⚠ Moderate: Auto-Delete ON only

  • Commands deleted automatically
  • But no PIN protection
  • Anyone with access to Controller's number could issue commands

⚠ Minimal: No PIN, Auto-Delete OFF

  • Anyone knowing commands can control app
  • Command history visible in SMS
  • Not recommended for sensitive operations

Streaming Commands​

START Stream:

1234 START
  • Begins live streaming to configured server
  • Sends stream link to all family contacts
  • Starts GPS location sharing
  • Begins auto-record (if enabled)

STOP Stream:

1234 STOP
  • Stops all active streaming
  • Ends auto-recording
  • Notifies family members stream ended
  • Preserves recorded files

VIDEO Mode:

1234 VIDEO
  • Switches from Audio Only to Video + Audio
  • Requires more bandwidth
  • Full quality streaming

AUDIO ONLY Mode:

1234 AUDIO ONLY
  • Reduces bandwidth significantly
  • Continues audio streaming
  • Useful for slow connections
  • Lower data usage

Camera Commands​

FLIP Camera:

1234 FLIP
  • Switches between front and back camera
  • Useful for changing perspective
  • Works during active streaming
  • Instant switch

FRONT Camera:

1234 FRONT
  • Force front camera on
  • Remains on front until switched
  • Good for selfie perspective
  • Stays on front after next stream

BACK Camera:

1234 BACK
  • Force back camera on
  • Better for wide-angle views
  • Remains on back until switched

Recording Commands​

RECORD ON:

1234 RECORD ON
  • Start recording video/audio
  • Saved to device storage
  • Works with or without streaming
  • Continues if app minimized

RECORD OFF:

1234 RECORD OFF
  • Stop active recording
  • Finalizes recorded file
  • Saves to configured folder

Status & Location Commands​

STATUS:

1234 STATUS

Returns:

  • Streaming status (ON/OFF)
  • Current mode (VIDEO or AUDIO)
  • Recording status
  • Active camera (FRONT/BACK)

LOCATION:

1234 LOCATION

Returns:

  • GPS coordinates (Latitude, Longitude)
  • Google Maps link for navigation
  • Timestamp of location reading
  • Accuracy information

HELP:

1234 HELP

Returns list of all available commands and brief descriptions.

Emergency Commands​

CALL ME:

1234 CALL ME
  • Initiates call back to Controller's number
  • Screen remains black (no display of activity)
  • Phone rings as normal incoming call
  • Useful for covert communication
  • Safe to answer during stressful situations

Command Tips & Tricks​

Formatting Rules​

  • Case doesn't matter: STATUS = status = Status
  • Space after PIN: 1234 STATUS ✓ (not 1234STATUS)
  • Single command per SMS: One command per message
  • Exact Controller number: Must come from registered number

Testing Commands​

Before emergencies, test your setup:

  1. Test PIN works:

    1234 STATUS

    Should get response, not be ignored

  2. Test without PIN (if no PIN configured):

    STATUS

    Should get response

  3. Test streaming:

    1234 START

    Then verify stream begins

  4. Test location:

    1234 LOCATION

    Should return coordinates

Command Combinations​

Send multiple commands in sequence:

Message 1: 1234 START           (Start streaming)
Wait 5 seconds...
Message 2: 1234 FLIP            (Switch camera)
Message 3: 1234 LOCATION        (Get coordinates)
Wait for stream to end...
Message 4: 1234 STOP            (Stop stream)

Troubleshooting Commands​

Commands Not Working:

  1. Verify PIN is correct

    • Check if PIN is set in settings
    • Include PIN prefix if configured
    • Use exact PIN (case-sensitive for numbers)

  2. Check Controller number

    • Ensure SMS comes from registered Controller
    • Verify phone number in Emergency Contacts
    • No command works if from wrong number

  3. Verify SMS permissions

    • Go to Settings > Apps > Link Up Elite > SMS
    • Grant SMS permission if needed
    • Restart app after granting

  4. Check commands are sent

    • Verify messages are actually being sent
    • Check phone has SMS service
    • Try a test text to Controller first

  5. Internet connection required

    • Some commands need data (START, LOCATION, etc.)
    • Ensure WiFi or cellular connected
    • STATUS doesn't require internet

Auto-Delete Not Working:

  1. Check SMS permissions

    • Go to Settings > Apps > Link Up Elite > Permissions
    • Verify SMS "Read" and "Delete" permissions
    • Grant if missing

  2. Check default SMS app

    • Go to Settings > Default Apps
    • Set Link Up Elite as default SMS app (if option available)
    • Some phones don't allow this

  3. Check Android version

    • Auto-delete works best on Android 10+
    • Older versions may have issues
    • Can manually delete messages if needed

Security Workflow​

Recommended Setup for Maximum Security​

Step 1: Enable PIN

Settings > Emergency Contacts > SMS Command Security
Enter PIN: 7392

Step 2: Enable Auto-Delete

Settings > Emergency Contacts > SMS Command Security
Auto-Delete Commands: ON

Step 3: Grant SMS Permissions

Settings > Apps > Link Up Elite > Permissions
SMS: Grant permission

Step 4: Test Setup

Have Controller send: 7392 STATUS
Verify response received
Verify message auto-deleted

Step 5: Train Controller

  • Teach Controller how to prefix PIN
  • Provide list of useful commands
  • Practice commands before emergencies

Operational Security Tips​

  1. Keep PIN private: Don't share via text or email
  2. Tell Controller in person: Share PIN face-to-face only
  3. Change PIN periodically: Every 6-12 months
  4. Monitor command responses: Check for unexpected activity
  5. Review auto-delete: Verify messages aren't in SMS inbox
  6. Test regularly: Monthly test of critical commands
  7. Backup procedures: Have backup commands list

Legal Considerations​

Legal Use of SMS Commands​

✓ Legal: Personal safety and family monitoring ✓ Legal: Authorized law enforcement operations ✓ Legal: Your own device and contacts ✓ Legal: Consensual monitoring with proper authorization

Potential Legal Issues​

✗ Illegal: Monitoring without consent (wiretapping laws) ✗ Illegal: Stalking or harassment ✗ Illegal: Unauthorized remote access ✗ Illegal: Violating privacy laws (GDPR, CCPA, etc.)

Privacy Compliance​

  • Inform monitored individuals about monitoring
  • Comply with local recording laws
  • Respect privacy laws in your jurisdiction
  • Consider obtaining written consent
  • Don't use for harassment or stalking
