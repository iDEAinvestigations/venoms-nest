Link Up Elite - Home Screen & SOS System

Home Screen Overview​

After launching Link Up Elite, you'll see the main interface with two prominent buttons and additional options.

Main Buttons​

🔴 SOS Button (Large Red Circle)​

  • Purpose: Emergency alert system
  • How to Use: Tap once (no holding required)
  • What Happens:
    1. SMS alerts sent to all emergency contacts
    2. Media streaming starts
    3. GPS location included
    4. Video/audio recording begins
    5. All contacts notified instantly

🔵 Check-In Button (Large Blue Button)​

Status shows one of two states:

StatusMeaningAction
"Start Check-In"Not currently streamingTap to begin live stream
"Stop Check-In"Currently streamingTap to end stream
  • Purpose: Live streaming to family members
  • How to Use: Tap to toggle streaming on/off
  • What Happens:
    • Video/audio stream starts
    • Family can watch in real-time
    • GPS location visible during stream

Secondary Buttons​

Below the main buttons are smaller icons/buttons for:

ButtonFunction
SettingsConfigure app (PIN required)
ContactsView/manage emergency contacts
HistoryView SOS and check-in logs
HelpIn-app help and tutorials

SOS System Explained​

What Triggers​

When you tap the SOS Button:

  1. SMS Messages Sent

    • Sent to up to 6 pre-configured emergency contacts
    • Message includes: Your location, media streaming link
    • Contains "SOS" in subject line for quick identification

  2. Media Streaming Starts

    • Video stream begins (if camera enabled)
    • Audio stream begins (if mic enabled)
    • Links included in SMS allow contacts to watch live

  3. GPS Location Shared

    • Current GPS coordinates sent with alert
    • Updates continuously during SOS event
    • Contacts can see real-time location if viewing stream

  4. Recording Begins

    • Video recording starts on device
    • Audio recording starts
    • Continues even if app minimized
    • Saved to device storage

  5. Automatic Features

    • If enabled: Screen record + camera record
    • Backup recording to cloud (if configured)
    • Encryption of sensitive data
    • Evidence preservation for authorities

Deactivating SOS​

To stop the SOS alert:

  1. Tap SOS Button Again - Stops the active SOS
  2. Confirmation Dialog appears
  3. Tap "Stop SOS" to confirm
  4. Recording stops, streaming ends
  5. Contacts notified that SOS has ended

Understanding SOS Messages​

When contacts receive your SOS:

Message Content:

EMERGENCY SOS ALERT
Name: [Your Name]
Location: [City, State]
GPS: [Latitude, Longitude]
Link: [Streaming URL]
Time: [Timestamp]

Contact Actions:

  • Can tap link to watch live stream
  • Can see your location on map
  • Can call you for voice contact
  • Should contact emergency services if needed

Managing Emergency Contacts​

Adding Emergency Contacts​

  1. Tap "Settings" button on home screen
  2. Enter your PIN to access settings
  3. Select "Emergency Contacts"
  4. Tap "Add Contact"
  5. Enter contact details:
    • Name: Contact's name (e.g., "Mom", "911")
    • Phone Number: Mobile number for SMS
    • Email (optional): For backup notifications
    • Relationship: Type of contact
  6. Tap "Save Contact"

Editing Contact Information​

  1. Go to Settings > Emergency Contacts
  2. Long-press the contact
  3. Tap "Edit"
  4. Update information
  5. Tap "Save"

Removing a Contact​

  1. Go to Settings > Emergency Contacts
  2. Long-press the contact
  3. Tap "Delete"
  4. Confirm deletion

Maximum Contacts​

  • Up to 6 emergency contacts can be configured
  • All receive alerts simultaneously when SOS triggered
  • Recommend including: family, friends, workplace security, medical personnel

Viewing SOS History​

Access History​

  1. From home screen, tap "History"
  2. List of past SOS events appears
  3. Each entry shows:
    • Date & Time: When SOS was triggered
    • Duration: How long SOS was active
    • Status: Completed, Cancelled, Error
    • Contacts Notified: How many received alert

Viewing Details​

  1. Tap any SOS event in history
  2. Full details appear:
    • Exact timestamp of trigger
    • GPS coordinates at time of SOS
    • Video/audio recording files
    • Contacts contacted and responses
    • Cloud backup status

Exporting SOS Records​

For authorities or insurance:

  1. Open SOS event details
  2. Tap "Export"
  3. Choose format: PDF or CSV
  4. File saved to device

Status Indicators​

Visual Feedback​

During SOS:

  • 🔴 Red flashing indicator at top of screen
  • "SOS ACTIVE" message visible
  • Countdown timer showing duration
  • Signal strength meter for streaming

During Check-In:

  • 🔵 Blue indicator shows active streaming
  • Live indicator (red dot) shows transmission
  • Viewers counter (how many watching)

Audio/Vibration Feedback​

  • SOS Start: Loud alert tone or vibration pattern
  • Check-In Start: Confirmation tone
  • Contact Reached: Success notification
  • Connection Loss: Alert tone if stream drops

Settings from Home Screen​

Quick access settings (PIN required):

  1. Tap Settings button
  2. Enter PIN (e.g., 1234#)
  3. Available options:
    • Emergency Contacts
    • Family Members
    • Streaming Preferences
    • Recording Options
    • Backup/Cloud
    • About/Help

Tips for Effective SOS Use​

  1. Test SOS Regularly: Send test SOS to verify it works
  2. Update Contacts: Ensure numbers are current
  3. Keep Phone Charged: SOS requires power for streaming/recording
  4. Known Location: Stay in areas with GPS/network signal
  5. Inform Contacts: Tell emergency contacts what SOS means
  6. Review History: Check logs to ensure system working
  7. Background Operation: App continues working even if minimized

Troubleshooting​

SOS Won't Send

  • Verify internet connection (WiFi or cellular)
  • Check contacts have valid phone numbers
  • Ensure location services enabled
  • Restart app and try again

Streaming Not Starting

  • Verify camera permission granted
  • Check internet connection strength
  • Ensure sufficient battery
  • Test by doing check-in instead of SOS

Contacts Not Receiving Messages

  • Verify phone numbers in emergency contacts
  • Check SMS carrier allows automated messages
  • Try re-adding contacts
  • Contact support@ideatech.us
