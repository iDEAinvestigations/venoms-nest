Link Up Elite - Advanced Features & Auto-Recovery

Auto-Recovery System (v2.1)​

The Advanced Auto-Recovery system ensures Link Up Elite continues operating reliably even when network conditions are poor or internet connection is temporarily lost.

Network Error Recovery​

What It Does:

  • Automatically detects connection loss
  • Attempts to reconnect within seconds
  • Resumes streaming without user intervention
  • Transparent to family members watching

How It Works:

  1. Detection: App monitors network connection continuously
  2. Loss Detected: If connection drops, app notes the time
  3. Immediate Retry: Attempts to reconnect within 1-2 seconds
  4. Streaming Resumed: If successful, streaming continues
  5. Notification: You receive notification of drop/recovery

Persistent Recording​

Continuous Recording Through Network Issues:

  • Recording continues even if streaming drops
  • Multiple copies created: Device + Cloud (if configured)
  • No gap in video/audio coverage
  • Timestamps preserved for evidence

Example:

Connection Timeline:
10:00 - Stream starts, recording starts
10:05 - Network drops
10:06 - Network reconnects, stream resumes
10:07 - Device recording: 7 minutes continuous
        Cloud recording: 5 minutes + 2 minutes files

Smart Battery Optimization​

Power Management:

  • Optimizes CPU usage during long operations
  • Reduces battery drain by 30-40% vs manual mode
  • Maintains full quality while extending runtime
  • Automatic power-saving thresholds

Battery Profiles:

ModeBattery UsageDurationQuality
High PerformanceMax power2-3 hoursFull 4K
BalancedModerate4-6 hours720p-1080p
Battery SaverLow power8+ hours480p
EmergencyMinimal12+ hoursAudio only

Automatic Switching:

  • Below 50% battery: Switches to Balanced
  • Below 25% battery: Switches to Battery Saver
  • Below 5% battery: Switches to Emergency (audio only)
  • Manual override available in settings

Background Operation Reliability​

Ensures App Continues:

  • Works reliably even when phone is locked
  • Survives app switcher/recent apps clearing
  • Recovers from accidental app closure
  • Maintains connection through screen off state

Background Protections:

  1. DozeMode Bypass: Exempt from Android power management
  2. Foreground Service: Uses notification to stay alive
  3. Wake Lock: Maintains CPU during critical moments
  4. Process Priority: High priority process in system
  5. Recovery Service: Background service monitors main app

Error Resilience​

Graceful Error Handling:

When errors occur:

  1. Detection: System identifies the problem
  2. Logging: Error details recorded for debugging
  3. Recovery: Attempts automatic fix
  4. Fallback: Switches to alternative method if needed
  5. Notification: User informed of issue and recovery

Types of Errors Handled:

  • Network connection failures
  • Camera/microphone access errors
  • Storage write failures
  • GPS signal loss
  • SMS sending failures
  • Encoding/streaming errors

Disguise Mode​

What It Does​

When the app goes to background, it displays a fake Google search screen to hide the app's operation.

How It Works​

  1. App Minimized: User exits app or home button pressed
  2. Disguise Screen Appears: Looks like normal Google search
  3. Protection: Anyone seeing phone won't know app is active
  4. Streaming Continues: App continues recording/streaming behind fake screen

Using Disguise Mode​

Activating:

  • Simply minimize the app (press home button)
  • Fake Google screen appears
  • Recording/streaming continues in background

Returning to App:

  • Triple-tap the Google logo
  • Link Up Elite returns to foreground
  • Resume monitoring where you left off

What Fake Screen Shows​

The disguise screen shows:

  • Google search bar
  • Suggested apps
  • Recent searches
  • "Normal" phone homescreen appearance
  • No indication app is recording

Privacy Benefits​

  • Covert Operation: Phone looks inactive to observers
  • No Evidence: Doesn't appear in recent apps during monitoring
  • Reversible: Quick triple-tap returns to app
  • Effective: Works even on locked screens
  • Customizable: Can adjust what search suggestions show

Call-Back with Black Screen​

What It Does​

When Controller sends "CALL ME" command, phone calls them with screen completely black. Provides covert communication option.

How It Works​

  1. Controller sends: CALL ME command (or 1234 CALL ME with PIN)
  2. Phone rings: Normal incoming call from your phone to Controller
  3. Black screen: Screen remains completely black when answered
  4. Communication: Can talk and listen normally
  5. Stealth: No indication on screen that call is active

Using Black Screen Calls​

For Controller:

Message: 1234 CALL ME
(Your phone rings their number)
They can answer (your phone, black screen)
Talk normally through phone speaker/earpiece

Use Cases:

  • Covert emergency communication
  • In situations where you can't unlock phone
  • When you need discreet contact
  • Safe for high-stress situations
  • No accidental button presses on screen

During Black Screen Call​

  • Full duplex: Two-way communication
  • Speaker optional: Can use earpiece
  • Microphone active: They hear you clearly
  • Location tracking: Still shares location (if enabled)
  • Recording continues: Recording doesn't stop during call

Location Sharing Options​

Share on SOS​

When SOS is triggered, automatically include location:

  • Current GPS coordinates
  • Google Maps link to location
  • Timestamp of location reading
  • Accuracy level of GPS fix

Enable/Disable:

Settings > Location Settings > Share Location on SOS

Share on Check-In​

When starting live stream, automatically include location:

  • Streaming begins
  • Location shared with all family members
  • Updates continuously during stream
  • Contacts see location in real-time

Enable/Disable:

Settings > Location Settings > Share Location on Check-In

Location Accuracy​

GPS Accuracy:

  • Excellent: 5-10 meters (outdoors, clear sky)
  • Good: 10-30 meters (outdoors, some obstruction)
  • Fair: 30-100 meters (urban, tall buildings)
  • Poor: 100+ meters (indoors, dense urban)

Improving Accuracy:

  • Go outside or near window
  • Wait 30-60 seconds for GPS fix
  • Use open area away from buildings
  • Avoid tunnels and metal structures
  • Check GPS permissions enabled

Multi-Contact Notifications​

"Link Us All" Feature​

Quick way to notify all contacts at once:

  1. Go to Emergency Contacts screen
  2. Tap "Link Us All" button
  3. Media streaming link sent to all contacts
  4. Each contact receives individual notification
  5. All can watch simultaneously

Notification Content​

Each contact receives:

[Your Name] is requesting connection
Stream Link: [URL to watch]
Duration: Live stream
Quality: [Resolution]
Tap link to watch live stream

Contact Limits​

  • Primary Contact (Controller): 1 contact
  • Additional Family Members: Up to 5 more
  • Total: Up to 6 contacts per configuration

Recording Options​

Auto-Record Settings​

Auto-Record on SOS:

  • Automatically starts recording when SOS triggered
  • Continues recording during entire SOS event
  • Captures evidence of emergency situation
  • Can disable if not needed

Auto-Record on Check-In:

  • Automatically starts recording when stream starts
  • Useful for documentation
  • Can be disabled for quick check-ins
  • Creates backup recording locally

Enable/Disable:

Settings > Recording Settings > Auto-Record on SOS
Settings > Recording Settings > Auto-Record on Check-In

DVR Test​

Test recording functionality before emergencies:

  1. Go to Settings > Recording Settings
  2. Tap "DVR Test"
  3. App records 10-30 second test video
  4. You see preview of recording
  5. Confirms system working properly

Recording Folder​

Set Custom Folder:

Settings > Recording Settings > Recording Folder
Select where to save recordings
Can be internal storage or SD card
Requires write permission to folder

Recommended Locations:

  • Device internal storage (safest)
  • Dedicated cloud backup folder
  • SD card (if available and reliable)

Recording Quality​

Options:

  • High Quality: 720p-1080p, larger files
  • Balanced: 480p-720p, medium files
  • Compression: Smaller files, lower quality
  • Audio Only: No video, smallest files

Quality vs. Size:

  • 720p video: ~200 MB per hour
  • 480p video: ~100 MB per hour
  • Audio only: ~20 MB per hour
  • Adjust based on storage space

Stream Quality Settings​

Resolution Options​

ResolutionBandwidthQualityUse Case
4K4+ MbpsHighestHigh-speed connections
1080p2-3 MbpsExcellentGood WiFi/cellular
720p1-2 MbpsGoodStandard connections

Setting Resolution:

Settings > Streaming Settings > Video Resolution
Choose highest quality your connection supports

Adaptive Streaming​

App automatically adjusts quality if:

  • Connection speed drops
  • Signal strength decreases
  • Too many people watching
  • Server capacity limits

Professional Features​

Server Configuration​

SRT Server URL:

Settings > Streaming Settings > SRT Server URL
Format: srt://your-server:port
Example: srt://broadcast.company.com:3333

RTMP Alternative:

Format: rtmp://your-server/live
Example: rtmp://streaming.server.com/live/stream-key

Authentication​

If server requires credentials:

  1. Contact your server administrator
  2. Server credentials typically in URL: 
    srt://username:password@server:port
  3. Or enter in app settings if available

Stream Key Management​

For services requiring stream keys:

  1. Generate key from your streaming provider
  2. Enter in SRT Server URL or settings
  3. Keep key confidential (like password)
  4. Rotate keys periodically for security

Cloud Backup Integration​

Automatic Cloud Backup​

Enable Cloud Backup:

Settings > Backup/Cloud > Enable Cloud Backup
Choose cloud provider (Google Drive, Dropbox, OneDrive)
Log in with your credentials

What Gets Backed Up:

  • All recorded videos and audio files
  • Configuration settings
  • Contact information
  • Emergency contact list
  • Location history (optional)

Does NOT Backup:

  • Your PIN (never stored anywhere)
  • Streaming server credentials (kept local)
  • Personal SMS messages
  • Phone contacts (only Link Up Elite contacts)

Backup Schedule​

Automatic Backup:

  • Triggers when new recordings complete
  • Occurs when device is on WiFi (to save data)
  • Uses background service
  • Doesn't interrupt streaming

Manual Backup:

Settings > Backup/Cloud > Backup Now
Immediately uploads pending files
Good before risky situations

Accessibility Features​

Text Size​

Adjust Button and Text Size:

Settings > Accessibility > Text Size
Options: Small, Normal, Large, Extra Large
Applies to all buttons and menus

Screen Brightness​

Auto Brightness:

Settings > Accessibility > Auto Brightness
Automatically adjusts to environment
Helps with battery life

Audio Features​

Audio Alerts:

Settings > Accessibility > Audio Alerts
Enable/disable notification sounds
Useful for hearing-impaired with other alerting

Performance Optimization​

Cache Clearing​

To free up space:

Settings > About > Clear Cache
Removes temporary files
Doesn't affect recordings or settings

Force Stop & Restart​

If app becomes unresponsive:

Settings > About > Force Stop
Wait 10 seconds
Reopen app (starts fresh)

Advanced Troubleshooting​

Debug Information​

To send detailed logs for support:

Settings > About > Send Logs to Support
Attaches detailed system information
Helps support team diagnose issues
Describe problem in email

Diagnostic Mode​

Enable for investigating issues:

Settings > Advanced > Diagnostic Mode
Creates detailed log of all operations
Useful for finding intermittent problems
Disable when done (uses some battery)
