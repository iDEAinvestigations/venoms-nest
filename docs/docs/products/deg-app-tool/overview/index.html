DEG App Tool - User-Agent Analyzer

The DEG App Tool suite includes a professional User-Agent Analyzer - a legitimate forensics tool that parses and analyzes HTTP User-Agent strings for digital investigations and OSINT work.

What Is a User-Agent?​

A User-Agent is a text string sent by every browser and app when accessing websites. It contains information about:

  • Browser type and version
  • Operating system and version
  • Device type and model
  • Platform architecture
  • App or browser being used

Example User-Agent Strings​

Chrome on Windows:

Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120.0.0.0 Safari/537.36

WhatsApp iOS:

WhatsApp/2.23.20 iOS/16.5.1

Googlebot (Search Engine):

Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)

Core Capabilities​

1. User-Agent Parsing​

  • Identifies browser type and version
  • Detects operating system and version
  • Determines device type (Desktop/Mobile/Tablet)
  • Recognizes device model and manufacturer
  • Identifies platform architecture (32-bit/64-bit)
  • Detects browser rendering engine

2. Advanced Bot Detection​

Identifies and categorizes:

  • Search Engine Bots: Googlebot, Bingbot, DuckDuckBot, Yahoo Slurp
  • Social Media Bots: Facebook, Twitter, LinkedIn, Pinterest, Instagram
  • Messaging App Bots: WhatsApp, Telegram, Discord, Slack
  • Automation Tools: Selenium, Puppeteer, Headless Chrome, PhantomJS
  • Command-Line Tools: cURL, Wget, Python Requests
  • Web Scrapers: Scrapy and custom bots

3. Security Indicators​

  • WebView detection (embedded browser)
  • Headless browser warnings
  • Electron app identification
  • Suspicious automation patterns
  • Bot confidence scoring

4. OSINT Analysis​

Provides contextual insights:

  • Device type interpretation
  • Security risk assessment
  • Bot behavior analysis
  • Automation detection
  • Privacy concern flagging

How It Works​

This is a PASSIVE ANALYSIS TOOL, not an active tracking system.

Typical Workflow​

  1. You share a link to your website via WhatsApp/Snapchat
  2. Someone clicks the link on their device
  3. Their device makes HTTP request to your server
  4. Your web server logs the request (including User-Agent)
  5. You extract User-Agent from logs using templates
  6. You paste it into the Analyzer
  7. Tool identifies what device/browser they used

What You Need​

To track WhatsApp/Snapchat clicks, you need ONE of:

  • Your own web server with log access
  • URL shortener with analytics (bit.ly, TinyURL)
  • Google Analytics on a website you control
  • Custom tracking page (can be built separately)

Investigation Value​

Device Fingerprinting​

Combining User-Agent with other data points:

  • User-Agent → Device and browser info (this tool)
  • IP Address → Geographic location (IP Lookup tool)
  • Timestamp → When they accessed
  • Referrer → How they found the link

Social Media Tracking​

Detect clicks from messaging apps:

  • WhatsApp Detection: Identify clicks from WhatsApp in-app browser
  • Snapchat Detection: Identify clicks from Snapchat in-app browser
  • Device Type: See what device they're using
  • Platform: Know if iOS, Android, Desktop

Bot Identification​

Recognize automated access:

  • Search engine crawlers
  • Social media bots
  • Spam bots and scrapers
  • Legitimate automation tools

Legal Considerations​

What's Legal​

✓ Analyzing User-Agents from your own logs ✓ Authorized investigations with proper warrants ✓ Tracking on your website (with privacy policy) ✓ Business analytics on your properties ✓ Security monitoring you control

What's Not Legal​

✗ Tracking without consent (GDPR/CCPA violations) ✗ Unauthorized surveillance or stalking ✗ Wiretapping or illegal monitoring ✗ Harassing or harming individuals

Requirements​

  • Privacy policy on your website
  • Proper consent mechanisms
  • Legal authorization for investigations
  • Compliance with local regulations

Data Privacy​

What This Tool Does NOT Do​

  • Send data to external servers
  • Store any user information
  • Track users across websites
  • Create user profiles
  • Store cookies or tracking data
  • Collect personal information

How It Works Safely​

  • All processing happens in your browser
  • No server-side data collection
  • No external API calls (except templates)
  • Client-side only analysis
  • No data transmission
  • Instant local processing

System Requirements​

  • Modern web browser (Chrome, Firefox, Safari, Edge)
  • JavaScript enabled
  • HTTPS connection (recommended)
  • No additional software needed
  • Works on desktop and mobile

Getting Started​

  1. Access the Tool: Open User-Agent Analyzer in DEG App Tool
  2. Test It: Use "Detect Mine" to see your browser's UA
  3. Paste Examples: Try example User-Agents from bot detection section
  4. Use Templates: Copy extraction templates for your platform
  5. Extract UAs: Pull User-Agents from your server logs
  6. Analyze: Paste into tool and see detailed results
