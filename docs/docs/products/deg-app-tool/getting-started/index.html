DEG App Tool - User-Agent Analyzer - Getting Started

Accessing the Tool​

  1. Navigate to the DEG App Tool interface
  2. Log in with your credentials
  3. Click "User-Agent" in the navigation menu
  4. The User-Agent Analyzer loads in your browser

Basic Usage​

Step 1: Get a User-Agent String​

You need a User-Agent string to analyze. Get one from:

Option A: Your Own Browser

  • Click "Detect Mine" button in the tool
  • Your current browser's User-Agent auto-fills
  • Useful for testing and learning

Option B: Server Logs

  • Extract from Apache: grep "User-Agent" /var/log/apache2/access.log
  • Extract from Nginx: awk '{print $12}' /var/log/nginx/access.log
  • Copy the User-Agent string

Option C: Email Headers

  • Gmail: Open email > Show original
  • Look for "User-Agent" header
  • Copy the value

Option D: Example Strings

  • Use examples from this guide (see Examples section)

Step 2: Paste into Analyzer​

  1. Click in the "User-Agent String" text box
  2. Paste your User-Agent string
  3. Remove any extra whitespace or line breaks
  4. Entire string should be on one line

Step 3: Click Analyze​

  1. Click the "Analyze" button
  2. Processing indicator appears briefly
  3. Results display below the input box

Step 4: Review Results​

Results show:

  • Browser: Type and version
  • Operating System: Type and version
  • Device Type: Desktop, Mobile, Tablet, Bot
  • Device Model: Specific model if detectable
  • Architecture: 32-bit or 64-bit
  • Platform: Engine and rendering info
  • Bot Type: If detected as bot
  • Security Indicators: Any warnings
  • OSINT Insights: Contextual information

Using Templates​

What Are Templates?​

Templates show how to extract User-Agent strings from different sources:

  • Web server logs
  • Email headers
  • Network packets
  • Testing tools
  • Application code

How to Use Templates​

  1. Scroll to "Extraction Templates" section
  2. Find the template for your source (Apache, Nginx, Gmail, etc.)
  3. Click the template card
  4. Command/instructions copy to clipboard
  5. Green notification confirms copy
  6. Paste into your terminal or tool

Example Workflow​

Scenario: Track WhatsApp Click​

Goal: Know what device clicked your link shared in WhatsApp

Step 1: Set Up Tracking

  • Host a website you control: https://your-site.com/page
  • Share link in WhatsApp: https://your-site.com/page
  • Someone clicks the link

Step 2: Extract User-Agent

  • SSH into your web server
  • Use Apache template: grep -i "whatsapp" /var/log/apache2/access.log
  • Look for entry like: 
    192.168.1.100 - - [15/Jan/2026:10:30:45] "GET /page HTTP/1.1" 200 1234 "-" "WhatsApp/2.23.20 iOS/16.5.1"

Step 3: Isolate User-Agent

  • Extract just the User-Agent part: WhatsApp/2.23.20 iOS/16.5.1

Step 4: Paste into Analyzer

  • Click "Detect Mine" or paste: WhatsApp/2.23.20 iOS/16.5.1
  • Click "Analyze"

Step 5: Review Results

  • Results show:
    • Browser: WhatsApp (in-app)
    • OS: iOS 16.5.1
    • Device: iPhone (estimated)
    • Insight: "Mobile iOS device accessed from WhatsApp app"

Step 6: Combine with IP Data

  • Take the IP from log: 192.168.1.100
  • Use IP Lookup tool to get location
  • Now you know: Device type + Location + Time

Understanding Results​

Result Categories​

Browser Information​

  • Type: Chrome, Firefox, Safari, Edge, Opera, etc.
  • Version: Complete version number
  • Engine: Rendering engine (WebKit, Blink, Gecko)
  • Build: Internal build information

Operating System​

  • Name: Windows, macOS, iOS, Android, Linux, Chrome OS
  • Version: Specific OS version number
  • Architecture: 32-bit or 64-bit
  • Platform: Additional platform details

Device Information​

  • Type: Desktop, Laptop, Tablet, Mobile Phone
  • Model: Specific device model if detectable
  • Manufacturer: Apple, Samsung, Google, etc.
  • Identifier: Device code if available

Bot Detection​

  • Is Bot?: Yes/No
  • Bot Type: Search engine, Social media, Automation tool, etc.
  • Purpose: What the bot does
  • Threat Level: Low, Medium, High (if applicable)

Security Indicators​

  • Headless Browser: Detected automated headless access
  • WebView: Embedded browser (not full browser)
  • Automation Tool: Selenium, Puppeteer, etc.
  • Suspicious Pattern: Unusual activity detected

OSINT Insights​

  • Device type interpretation
  • Common use cases for this device
  • Security considerations
  • Investigation recommendations

Clear & Reset​

Clear Results​

  1. Click "Clear" button
  2. Text box empties
  3. Previous results disappear
  4. Ready for new User-Agent

Start Over​

  1. Click "Detect Mine" to auto-populate with your browser UA
  2. Click "Clear" then paste different User-Agent
  3. Each analysis is independent

Tips & Tricks​

Copy User-Agents Easily​

From Linux/Mac Terminal:

# Apache logs
grep "User-Agent" /var/log/apache2/access.log | head -1

# Nginx logs
tail -20 /var/log/nginx/access.log | grep "WhatsApp"

# Save to file
grep -i "whatsapp" /var/log/apache2/access.log | awk '{print $NF}' > user-agents.txt

From Email Headers:

  1. Open email in Gmail
  2. Click three dots (⋮)
  3. Select "Show original"
  4. Search for "User-Agent" on the page
  5. Copy the entire value

Common Questions​

Q: Can I see who clicked my link?​

A: The User-Agent Analyzer shows what DEVICE accessed your link, not who the person is. To identify individuals, you need additional methods like:

  • IP address (location only, not identity)
  • Account access logs
  • Device fingerprinting
  • Other OSINT techniques

Q: Does this track people?​

A: NO. This tool only analyzes User-Agent strings from data you already have. It doesn't:

  • Send tracking URLs
  • Track clicks in real-time
  • Collect data from users
  • Follow people across the internet
  • Store any information

Q: Is this legal?​

A: Using User-Agent data depends on context:

  • ✓ Legal: Analyzing logs from your own website
  • ✓ Legal: Authorized law enforcement investigations
  • ✗ Illegal: Tracking without consent (GDPR/CCPA)
  • ✗ Illegal: Unauthorized surveillance

Q: How accurate is device detection?​

A: Generally accurate for:

  • Browser type and version (95%+)
  • Operating system and version (95%+)
  • Device type (95%+)
  • Device model (80-90%)

Less accurate for:

  • Exact device model on some phones
  • Custom or spoofed User-Agents
  • Very new devices

Q: Can people hide their User-Agent?​

A: Yes, User-Agents can be modified, but:

  • Most people don't change theirs
  • Professional investigations use multiple data points
  • Spoofed UAs appear suspicious
  • Combine with IP data for better accuracy

Mobile Usage​

The analyzer works on mobile browsers:

  • Tap "Detect Mine" to see your mobile browser's UA
  • Paste User-Agents from email or messages
  • Results display in mobile-friendly format
  • Templates work on mobile (copy still works)

Troubleshooting​

Results Not Showing​

  1. Check browser's JavaScript is enabled
  2. Paste complete User-Agent string (single line)
  3. Refresh the page (Ctrl+R)
  4. Try different browser
  5. Clear browser cache if persistent

Copy Not Working​

  1. Verify JavaScript enabled
  2. Try clicking again
  3. Check if green notification appears
  4. Try different browser
  5. Use manual copy (Ctrl+C)

Unusual Results​

  1. Verify User-Agent string is correct (not truncated)
  2. Check for special characters that break parsing
  3. Try example User-Agents from guide
  4. Refresh page and try again
