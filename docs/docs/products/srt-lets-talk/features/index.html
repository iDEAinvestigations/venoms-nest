SRT Let's Talk - Features & Capabilities

Home Screen Interface​

LINE Button​

  • Primary Function: Instantly call your Mediator
  • Location: Center of home screen
  • Status: Green (ready) or Red (calling)
  • How to Use: Single tap to initiate call

Check-In Button​

  • Status Display: Shows current streaming state
  • "Start Check-In": Not currently streaming - tap to begin
  • "Stop Check-In": Currently streaming - tap to end
  • Purpose: Live stream to all Viewer contacts
  • Access: Large blue button below LINE button

Status Indicators​

Located at top of screen:

  • Streaming Status: ON/OFF indicator
  • Recording Status: ON/OFF indicator
  • Location Status: GPS active/inactive
  • Signal Strength: WiFi/cellular signal

Secondary Buttons​

  • Settings: Configuration (PIN required)
  • Contacts: Manage Mediator and Viewers
  • Help: In-app tutorials and FAQs

Streaming Modes​

Video + Audio (Default)​

  • Resolution Options: 360p, 480p, 720p, 1080p, 4K
  • Bandwidth Usage: Varies by resolution
  • Best For: Full HD professional streaming
  • Quality: Highest quality option

Audio Only​

  • Bandwidth Usage: Minimal
  • Best For: Low-speed internet connections
  • Quality: Full audio quality maintained
  • Use Case: When video not needed or bandwidth limited

Switching Modes​

  • Tap Settings > Streaming Settings
  • Select Stream Mode
  • Choose Video+Audio or Audio Only
  • Changes take effect immediately

Contact Management​

Mediator Contact​

  • Role: Primary contact with SMS command access
  • Access Level: Full control of app via SMS commands
  • Phone Number: Required to receive alerts
  • Configuration: Settings > Mediator Settings
  • Limit: Only 1 Mediator allowed

Viewer Contacts (1-10)​

  • Role: Receive notifications and stream links
  • Access Level: Can watch stream but cannot control app
  • Notification: Alerted when streaming starts
  • Share Link: Get URL to view live stream
  • Limit: Up to 10 Viewer contacts

Adding Contacts​

  1. Open Settings
  2. Enter your PIN
  3. Go to Mediator Settings
  4. For Mediator: Enter phone number
  5. For Viewers: Add contact name and phone number
  6. Save each contact

Editing Contacts​

  1. Go to Contacts tab
  2. Tap contact to edit
  3. Update phone number or details
  4. Tap "Save"

Recording Features​

Auto-Record Modes​

Auto-Record on LINE

  • Automatically starts recording when LINE button pressed
  • Continues recording during call
  • Useful for documenting communications
  • Enable in: Settings > Recording Settings

Auto-Record on Check-In

  • Automatically starts recording when streaming
  • Captures both video and audio
  • Useful for streaming documentation
  • Enable in: Settings > Recording Settings

Recording Storage​

  • Default Location: Device internal storage
  • Custom Folder: Can specify alternate location
  • File Format: MP4 video with audio
  • File Size: Depends on resolution and duration

DVR Test​

  • Purpose: Test camera and recording before operations
  • How to Use: Settings > Recording Settings > DVR Test
  • Duration: Records 10-30 second test video
  • Result: Allows you to verify setup works

Accessing Recordings​

  1. Open Settings
  2. Go to Recording Settings
  3. Tap "View Recordings"
  4. Select recording to view
  5. Playback or share as needed

Location Features​

GPS Location Sharing​

Share Location on LINE

  • Include current GPS coordinates when calling Mediator
  • Coordinates sent with call initiation
  • Allows Mediator to know your location
  • Enable in: Settings > Location Settings

Share Location on Check-In

  • Include GPS when starting stream
  • Location updates continuously during stream
  • Visible to all Viewer contacts
  • Enable in: Settings > Location Settings

Floor Level Detection​

How It Works

  • Uses phone's barometric pressure sensor
  • Calculates altitude changes from calibrated ground level
  • Estimates floor based on ~3 meters (10 feet) per floor
  • Reports: "Ground Floor", "1st Floor", "2nd Floor", etc.
  • Detects basement levels: "Basement 1", "Basement 2", etc.

Calibration Process

  1. Go to Settings
  2. Navigate to Floor Detection
  3. Stand on the ground floor of your building
  4. Tap "Calibrate Ground Floor"
  5. Calibration is saved and valid for 24 hours

Location Response Example

Location: 41.878113, -87.629799
Floor: 3rd Floor
https://maps.google.com/?q=41.878113,-87.629799

Important Notes

  • Requires phone with barometric pressure sensor
  • Accuracy depends on weather conditions
  • Re-calibrate when moving to new building
  • Calibration expires after 24 hours
  • Weather pressure changes can affect accuracy

SMS Command Security​

Purpose​

Protect your app from unauthorized SMS control with PIN protection and automatic message deletion.

Command PIN Prefix​

Set a secret PIN that must be included at start of every SMS command:

Example with PIN "7890"

7890 STATUS          → Get app status
7890 START           → Start streaming
7890 LOCATION        → Get current location
7890 CALL ME         → Initiate call back

Without PIN

STATUS               → Get app status
START                → Start streaming
LOCATION             → Get location

Auto-Delete Commands​

When enabled, SMS commands from Mediator are automatically deleted after processing:

  • Commands deleted within 1-2 seconds
  • Keeps command history invisible in messaging app
  • Response messages still sent to Mediator
  • Only works if SMS permissions granted

Configuration​

  1. Open SRT Let's Talk
  2. Enter your PIN to access Mediator Settings
  3. Scroll to "SMS Command Security"
  4. Enter desired Command PIN Prefix
  5. Toggle "Auto-Delete Commands" on/off
  6. Save settings

Security Best Practices​

  • Use unique PIN (avoid 1234, 0000, etc.)
  • Share PIN only with trusted Mediator
  • Enable Auto-Delete for maximum privacy
  • Change PIN periodically for security

Home Screen Widget​

What Is The Widget?​

A dedicated home screen icon for the LINE button that works even when app is closed.

Adding The Widget​

Automatic Method (during setup):

  1. Open SRT Let's Talk
  2. During setup, tap "Add Widget Automatically"
  3. Confirm when prompted
  4. Widget appears on home screen

Manual Method:

  1. Long-press on empty space on home screen
  2. Select "Widgets"
  3. Find "SRT Let's Talk" in widget list
  4. Drag the LINE widget to home screen
  5. Resize if desired

Using The Widget​

  • Tap LINE button widget to instantly call Mediator
  • Works even when app is closed
  • Large icon for easy access
  • Same functionality as in-app LINE button
  • Notification shows call is connected

Troubleshooting Widget​

  • Some launchers don't support widgets
  • Try different launcher if issues
  • Restart phone after installing app
  • Manually add widget if automatic failed

Professional Interface​

Design Elements​

  • Color Scheme: Navy Blue, Gold, White
  • Button Sizes: Large, easy-to-tap buttons
  • Font: Clear, readable typography
  • Contrast: Professional but clean appearance

User Experience​

  • Minimalist Design: Only essential controls visible
  • Large Buttons: Easy to use in emergencies
  • Clear Status: Instant visibility of app state
  • Responsive: Quick response to user actions

Customization​

  • Theme: Professional default theme
  • Font Size: Can adjust in Accessibility settings
  • Button Behavior: Standard single-tap controls
  • Notifications: Customizable alert sounds
