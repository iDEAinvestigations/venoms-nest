SRT Let's Talk Installation & Setup

System Requirements​

  • Android 8.0 or higher
  • 150MB free storage minimum
  • Internet connection (WiFi or cellular)
  • Valid SRT Let's Talk license key
  • All required permissions enabled

Installation Steps​

Step 1: Download APK​

  1. Visit apps.ideatech.us
  2. Select SRT Let's Talk v1.0
  3. Download the APK to your device

Step 2: Enable Unknown Sources​

  1. Open Settings
  2. Go to Security or Apps
  3. Enable "Install from Unknown Sources"

Step 3: Install App​

  1. Open Downloads folder
  2. Tap SRTLetsTalk.apk
  3. Tap "Install"
  4. Wait for completion

First Launch & Activation​

License Activation​

  1. Open SRT Let's Talk
  2. Activation Screen appears
  3. Enter your license key when prompted
  4. Tap "Activate"
  5. Wait for online verification
  6. Success screen confirms activation

Permission Grants​

SRT Let's Talk requires several permissions. Grant when prompted:

PermissionRequiredPurpose
LocationYesGPS location sharing and floor detection
CameraYesVideo streaming
MicrophoneYesAudio streaming and communication
Phone StateYesHandle calls during recording
OverlayYesHome screen widget operation
SMSYesSend and receive Mediator commands
PhoneYesMake/receive calls with Mediator

Grant ALL permissions for full functionality.

Battery Optimization (Samsung Devices)​

  1. You may see a Battery Optimization screen
  2. Follow instructions to exempt app from battery optimization
  3. Required for reliable background operation
  4. Can skip for now, but setup later in Settings

Overlay Permission (Android 6.0+)​

  1. App requests "Display over other apps" permission
  2. Grant permission for widget to work properly
  3. Required for home screen LINE widget
  4. Go to: Settings > Apps > Special Access > Display over other apps

Initial PIN Setup​

IMPORTANT: Remember this PIN

  1. On PIN Setup Screen, create a 4+ digit PIN
  2. PIN protects all settings and SMS commands
  3. Re-enter PIN to confirm
  4. Tap "Set PIN"

Never share your PIN with anyone

If you forget your PIN:

  • Reset requires support intervention
  • Contact support@ideatech.us with license key proof
  • Cannot reset without contacting support

Consent & Legal​

Terms of Use​

  1. You'll see the Consent Screen
  2. Read terms carefully
  3. Explains what app does and data usage
  4. Tap "I Agree" to proceed

Understanding the Agreement​

By accepting, you acknowledge:

  • The app can record audio and video
  • The app will access your location
  • The app may send data to your Mediator
  • You will use the app legally and responsibly
  • You have obtained necessary consent from monitored individuals

Home Screen Widget Setup​

Automatic Setup​

  1. During initial setup, you'll see "Add Widget Automatically" option
  2. Tap "Yes" to add widget
  3. Confirm when prompted
  4. Widget appears on your home screen

Manual Widget Addition​

If you skip automatic setup:

  1. Long-press on empty space on your home screen
  2. Select "Widgets"
  3. Find "SRT Let's Talk" in the widget list
  4. Drag the LINE widget to your home screen
  5. Resize if desired

The LINE button widget allows instant calling without opening the app.

Completing Setup​

After all permissions and setup screens:

  1. You're taken to the Home Screen
  2. You'll see the large LINE button in the center
  3. Below are: Check-In, Settings, Contacts, Help
  4. Home screen widget appears (if enabled)
  5. Additional setup recommended:
    • Add your Mediator
    • Add Viewer contacts
    • Configure streaming server
    • Calibrate floor detection

Recommended Next Steps​

  1. Add Mediator: Settings > Mediator Settings
  2. Add Viewers: Settings > Mediator Settings > Viewers
  3. Configure Streaming: Settings > Streaming Settings
  4. Calibrate Floor: Settings > Floor Detection > Calibrate
  5. Set Recording Options: Settings > Recording Settings
  6. Configure SMS Security: Settings > SMS Command Security

Troubleshooting Setup​

License Won't Activate

  • Ensure internet connection
  • Check license key spelling
  • Contact support@ideatech.us

Permissions Keep Requesting

  • Go to: Settings > Apps > SRT Let's Talk > Permissions
  • Manually grant all required permissions
  • Restart app

Widget Not Appearing

  • Some launchers don't support all widgets
  • Try manual widget addition method
  • Restart phone after installing app

Stuck on Permission Screen

  • Manually grant permission in: Settings > Apps > Permissions
  • Then return to app and proceed

Uninstalling SRT Let's Talk​

To uninstall:

  1. Open Settings > Apps
  2. Find SRT Let's Talk
  3. Tap "Uninstall"
  4. Confirm deletion

All data will be permanently deleted.
