SRT Let's Talk - Troubleshooting Guide

Streaming Issues​

Streaming Won't Start​

Problem: Check-In button doesn't initiate streaming

Solutions:

  1. Check your Share Link (SRT Server URL) is correct
    • Go to Settings > Streaming Settings
    • Verify URL format: srt://your-server:port
  2. Ensure you have internet connection (WiFi or cellular)
  3. Verify camera and microphone permissions are granted
  4. Try switching to Audio Only mode for low bandwidth
  5. Restart the app and try again
  6. Check if server is online and accepting connections

Poor Stream Quality​

Problem: Streaming is choppy, pixelated, or buffering

Solutions:

  1. Check your internet speed (need at least 2 Mbps for 720p)
  2. Switch to lower resolution
    • Go to Settings > Streaming Settings
    • Try 480p or 360p instead of 1080p
  3. Use Audio Only mode to reduce bandwidth
  4. Move closer to WiFi router or try cellular data
  5. Close other apps using network (downloads, streaming)
  6. Reduce background app activity

Stream Disconnects​

Problem: Stream keeps dropping connection

Solutions:

  1. Check internet stability
    • WiFi: Check signal strength and move closer
    • Cellular: Try different location for better signal
  2. Disable battery optimization for SRT Let's Talk
  3. Enable WiFi calling if available (more stable)
  4. Try audio-only mode first to test connection
  5. Update to latest app version
  6. Check SRT server is still running and accepting connections

LINE Button Issues​

LINE Button Not Working​

Problem: LINE button doesn't initiate call to Mediator

Solutions:

  1. Verify Mediator phone number is entered correctly
    • Go to Settings > Mediator Settings
    • Check for correct format and area code
  2. Ensure phone call permission is granted
    • Settings > Apps > SRT Let's Talk > Permissions > Phone
  3. Check that your phone has cellular service
    • Signal bars visible at top of screen
  4. Verify Mediator number is active and correct
  5. Try restarting the app
  6. Restart your phone if issue persists

Call Drops Immediately​

Problem: Call connects but drops after 1-2 seconds

Solutions:

  1. Check cellular signal - may have weak coverage
  2. Verify Mediator can receive calls (not on another call)
  3. Disable WiFi calling if enabled
  4. Use airplane mode test
    • Enable airplane mode for 10 seconds
    • Disable airplane mode
    • Try calling again
  5. Contact Mediator to verify their phone works
  6. Try calling from regular phone to test connectivity

Black Screen Call Not Working​

Problem: "CALL ME" command doesn't result in black screen

Solutions:

  1. Verify CALL ME command sent correctly with PIN if configured
  2. Check that black screen feature enabled in settings
  3. Ensure Mediator phone number correct in settings
  4. Try regular LINE button call to test connection
  5. Verify phone has latest security updates
  6. Some phones may not support black screen feature

SMS Command Issues​

SMS Commands Not Working​

Problem: Mediator sends commands but app doesn't respond

Solutions:

  1. Verify Mediator phone number matches exactly in settings
  2. Check if PIN is configured
    • If yes: Mediator must include PIN prefix: 7890 STATUS
    • If no: Send command without PIN
  3. Ensure SMS permissions are granted to app
  4. Commands must come from exact Mediator number
  5. Try sending HELP command first to test
  6. Check SMS receiving works (try texting yourself)

Commands Being Deleted Too Fast​

Problem: Can't see Mediator's SMS command messages

Solutions:

  1. This is expected if Auto-Delete is enabled
    • Auto-Delete removes commands within 1-2 seconds
  2. To keep commands visible:
    • Settings > SMS Command Security
    • Disable "Auto-Delete Commands"
  3. Response messages still sent to Mediator
  4. Disabling Auto-Delete reduces privacy slightly

Commands Not Being Deleted​

Problem: Auto-Delete enabled but messages still visible

Solutions:

  1. SRT Let's Talk must have full SMS permissions
    • Go to Settings > Apps > SRT Let's Talk > Permissions > SMS
    • Ensure all SMS permissions granted
  2. Another app may be default SMS handler
    • Go to Settings > Apps > Default Apps
    • Set SRT Let's Talk as default (if option available)
  3. Some phones don't support Auto-Delete feature
    • Works best on Android 10 and higher
  4. Try disabling and re-enabling Auto-Delete

Floor Detection Issues​

Floor Detection Not Available​

Problem: Floor level not included in location responses

Solutions:

  1. Check if phone has barometric pressure sensor
    • Not all phones have this sensor
    • Check phone specs online
  2. Ensure location permissions granted
  3. Calibrate floor detection
    • Go to Settings > Floor Detection
    • Tap "Calibrate Ground Floor"
    • Stand on actual ground floor
  4. Check if 24-hour calibration expired
    • Re-calibrate when moving buildings
  5. Go outside or near window for better accuracy

Floor Level Inaccurate​

Problem: Reported floor is incorrect (says 3rd when you're on 2nd)

Solutions:

  1. Re-calibrate on actual ground floor
    • Must calibrate on real ground floor (not basement)
    • Press firmly for accurate reading
  2. Weather/pressure changes can affect accuracy
    • Barometer affected by weather patterns
    • Re-calibrate if weather changed significantly
  3. Calibration expires after 24 hours
    • Re-calibrate daily if using frequently
  4. Large altitude differences may affect accuracy
    • Works best in normal building heights
    • May be inaccurate in very tall buildings (50+ floors)

Calibration Not Saving​

Problem: Floor detection still showing incorrect floor after calibration

Solutions:

  1. Ensure you're on actual ground floor when calibrating
  2. Stand still for 5 seconds during calibration
  3. Grant location permission if not already granted
  4. Restart app after calibration
  5. Try manual calibration again if first attempt failed
  6. Check if phone's pressure sensor working (manufacturer support)

Widget Issues​

Widget Not Appearing​

Problem: Home screen widget not visible after installation

Solutions:

  1. Some launchers don't support widgets
    • Try using Android default launcher
  2. Try manual widget addition method:
    • Long-press home screen > Widgets > SRT Let's Talk
  3. Restart phone after installing app
  4. Try adding widget to different home screen page
  5. Update launcher to latest version
  6. Restart the app before trying to add widget again

Widget Not Responding​

Problem: Tapping widget LINE button doesn't work

Solutions:

  1. App may need permissions granted
    • Open app directly and grant all permissions
    • Then try widget again
  2. Overlay permission required
    • Settings > Apps > SRT Let's Talk > Special Access > Display Over Other Apps
  3. Remove and re-add widget
    • Long-press widget > Remove
    • Long-press home screen > Widgets > Add SRT Let's Talk again
  4. Restart phone to refresh widget cache
  5. Some launchers have widget issues (try default launcher)

App Closes or Crashes​

App Closes in Background​

Problem: App stops running when you minimize it

Solutions:

  1. Disable battery optimization for SRT Let's Talk
    • Settings > Battery > Battery Optimization
    • Find SRT Let's Talk > Select > Don't Optimize
  2. Complete Samsung battery setup (Samsung devices only)
    • During setup or Settings > Battery > More Options
  3. Grant overlay permission
    • Settings > Apps > SRT Let's Talk > Special Access > Display Over Other Apps
  4. Keep app in recent apps list
    • Don't swipe app away from recent apps
  5. Disable aggressive task killers if installed

App Crashes on Startup​

Problem: App closes immediately after opening

Solutions:

  1. Clear app cache
    • Settings > Apps > SRT Let's Talk > Storage > Clear Cache
  2. Restart your phone
  3. Update app to latest version
  4. Check storage space
    • Need at least 150MB free
    • Delete files if storage full
  5. Uninstall and reinstall app
  6. Contact support if problem persists

App Freezes During Operation​

Problem: App becomes unresponsive or stuck

Solutions:

  1. Force stop the app
    • Settings > Apps > SRT Let's Talk > Force Stop
  2. Wait 10 seconds then reopen
  3. Clear app cache (Settings > Apps > Storage > Clear Cache)
  4. Restart your phone
  5. Update app if new version available
  6. Uninstall and reinstall if problem continues

Location & Permission Issues​

Location Not Available​

Problem: Cannot get GPS location or location always fails

Solutions:

  1. Enable GPS/Location services
    • Settings > Location > Turn On
  2. Grant location permissions
    • Settings > Apps > SRT Let's Talk > Permissions > Location
  3. Go outside or near window for GPS signal
    • Requires 4+ satellites for accurate location
  4. Wait 1-2 minutes for GPS to acquire signal
  5. Try again in open area away from buildings
  6. Restart phone if GPS not working

Permissions Keep Requesting​

Problem: App keeps asking for same permission repeatedly

Solutions:

  1. Manually grant permission in system settings
    • Settings > Apps > SRT Let's Talk > Permissions
    • Toggle each permission ON
  2. Restart app after granting permissions
  3. Restart phone to ensure permissions apply
  4. Check if permissions toggled off
    • Go to settings and verify they're ON
  5. Uninstall and reinstall app if persistent

Contact & Support Issues​

Mediator Not Receiving Alerts​

Problem: Mediator says they're not getting notifications

Solutions:

  1. Verify Mediator phone number is correct in settings
  2. Check that notifications enabled on Mediator's phone
  3. Try sending test SMS manually to Mediator
  4. Verify Mediator's phone is on and has signal
  5. Check if Mediator has SRT Let's Talk notifications disabled
  6. Try removing and re-adding Mediator contact

Cannot Add Contacts​

Problem: Can't add or edit Mediator or Viewer contacts

Solutions:

  1. Enter PIN to access settings
    • Contacts require PIN protection
  2. Go to Settings > Mediator Settings
  3. Ensure you're entering phone numbers correctly
    • Include area code: +1-708-808-0719 or 708-808-0719
  4. Save each contact after entering info
  5. Try clearing contacts and re-adding
  6. Restart app if changes not saving

General Issues​

App Slowing Down Phone​

Problem: Phone becomes slow after running SRT Let's Talk

Solutions:

  1. Close other apps running in background
  2. Clear app cache periodically
    • Settings > Apps > SRT Let's Talk > Storage > Clear Cache
  3. Update app to latest version
  4. Restart phone to clear memory
  5. Check storage isn't full (need 150MB free)
  6. Disable continuous location sharing if not needed

High Battery Drain​

Problem: SRT Let's Talk using lots of battery

Solutions:

  1. Reduce video resolution to lower setting
  2. Use audio-only mode when possible
  3. Disable auto-record features
  4. Reduce screen brightness on your phone
  5. Disable GPS when not needed
  6. Disable WiFi and Bluetooth when not needed
  7. Limit streaming duration

Getting Help​

Sending Debug Logs to Support​

  1. Open SRT Let's Talk
  2. Enter PIN to access Settings
  3. Scroll to "About" section
  4. Tap "Send Logs to Support"
  5. Email will open with logs attached
  6. Describe your issue in detail
  7. Send to support@ideatech.us

Always include:

  • Device model and Android version
  • App version (visible in About)
  • Description of the problem
  • Steps to reproduce the issue
