SRT Let's Talk - Complete Settings Guide

Access Settings by tapping the Settings button and entering your PIN.

Streaming Settings​

Share Link (SRT Server URL)​

  • What it is: Your streaming server address
  • Format: srt://your-server.com:port or rtmp://your-server.com/path
  • Where to get it: Contact your streaming service provider
  • Example: srt://stream.example.com:10080
  • How to configure:
    1. Go to Streaming Settings
    2. Tap "Share Link"
    3. Enter your server URL
    4. Tap "Save"

Stream Mode​

  • Video + Audio (Default): Full quality with video and audio
  • Audio Only: Low bandwidth, audio only
  • How to change:
    1. Go to Streaming Settings
    2. Select "Stream Mode"
    3. Choose Video+Audio or Audio Only
    4. Changes take effect immediately

Video Settings​

  • Enable Video: Toggle video streaming on/off
  • Enable Audio: Toggle audio streaming on/off
  • Resolution: Choose 360p, 480p, 720p, 1080p, or 4K
  • Front Camera Default: Force front camera on startup
  • Bandwidth Guide:
    • 360p: ~1 Mbps
    • 480p: ~2 Mbps
    • 720p: ~3-4 Mbps
    • 1080p: ~5-8 Mbps
    • 4K: ~15+ Mbps

Mediator Settings​

Add Mediator Contact​

  • Phone Number: Primary contact with SMS command access
  • Format: Include area code (e.g., +1-708-808-0719)
  • Limit: Only 1 Mediator allowed
  • How to add:
    1. Go to Mediator Settings
    2. Tap "Add Mediator"
    3. Enter phone number
    4. Tap "Save"

Add Viewer Contacts (1-10)​

  • What are Viewers: Receive stream notifications and links
  • How to add:
    1. Go to Mediator Settings
    2. Tap "Add Viewer"
    3. Enter contact name and phone number
    4. Tap "Save"
  • Notifications: Viewers notified when streaming starts
  • Access: Viewers can watch but cannot control app

Edit or Remove Contacts​

  • Edit: Tap contact name to modify details
  • Remove: Tap contact, then "Delete"
  • Save changes immediately

Recording Settings​

Recording Folder​

  • Default: Device internal storage
  • Custom Folder: Specify alternate location
  • How to change:
    1. Go to Recording Settings
    2. Tap "Recording Folder"
    3. Navigate to desired folder
    4. Tap "Select This Folder"
  • Ensure adequate storage (at least 500MB free)

Auto-Record Options​

Auto-Record on LINE

  • Automatically start recording when LINE button pressed
  • Useful for documenting Mediator calls
  • Toggle ON/OFF in Recording Settings

Auto-Record on Check-In

  • Automatically start recording when streaming begins
  • Captures full streaming session
  • Toggle ON/OFF in Recording Settings

DVR Test​

  • Purpose: Test camera and recording before operations
  • How to run:
    1. Go to Recording Settings
    2. Tap "DVR Test"
    3. App records 10-30 second test video
    4. Review recording to verify setup
  • Use before emergencies to ensure everything works

Playback & Management​

  • View Recordings: Opens recordings folder
  • Delete: Long-press recording to delete
  • Share: Tap recording to share via email/messaging
  • Storage: Monitor available disk space

Location Settings​

Share Location on LINE​

  • Purpose: Send GPS coordinates when calling Mediator
  • Include Location: Toggle ON/OFF
  • When enabled: Location sent automatically with LINE call
  • Updates: Location updates in real-time

Share Location on Check-In​

  • Purpose: Send GPS when streaming starts
  • Include Location: Toggle ON/OFF
  • When enabled: Location sent to all Viewer contacts
  • Continuous updates: Location updates during stream

GPS Configuration​

  • Enable GPS: Ensure Location Services enabled in phone Settings
  • Accuracy: Higher accuracy takes longer to acquire signal
  • Outdoor use: Works best outside or near windows
  • Accuracy range: Typically 5-30 meters

Floor Detection​

Calibration​

  • Barometric Sensor: Uses phone's pressure sensor
  • How to calibrate:
    1. Go to Floor Detection
    2. Stand on actual ground floor of building
    3. Tap "Calibrate Ground Floor"
    4. Stand still for 5 seconds
    5. Calibration saved
  • Validity: Calibration valid for 24 hours
  • Re-calibrate when moving to different building

How It Works​

  • Estimation: Calculates ~3 meters (10 feet) per floor
  • Accuracy: Best in normal building heights
  • Weather effects: Barometric pressure changes affect accuracy
  • Floor reporting: Shows "Ground", "1st Floor", "2nd Floor", etc.

Understanding Results​

  • Ground Floor: Baseline for calibration
  • Positive floors: Above ground level (1st, 2nd, 3rd, etc.)
  • Basement: Below ground level (-1, -2, etc.)
  • Accuracy: ±1 floor typical accuracy

Troubleshooting Floor Detection​

  • Phone lacks sensor: Not all phones have barometric sensor
  • Inaccurate readings: Re-calibrate on actual ground floor
  • After weather change: Recalibrate if major pressure change
  • Moving buildings: Always recalibrate in new building

SMS Command Security​

Command PIN Prefix​

  • Purpose: Prevent unauthorized app control
  • How to set:
    1. Go to SMS Command Security
    2. Tap "Command PIN Prefix"
    3. Enter your desired PIN (4+ digits)
    4. Mediator must include PIN in every command
  • Example with PIN "7890":
    • Command: 7890 START
    • Invalid: START (missing PIN)
    • Invalid: 7890START (missing space)

Auto-Delete Commands​

  • Purpose: Automatically remove command SMS messages
  • How it works: Deletes message within 1-2 seconds of processing
  • Requirements: Requires full SMS permissions
  • Enable/Disable: Toggle in SMS Command Security
  • Benefits: Privacy - command history invisible
  • Note: Response messages still sent to Mediator normally

Mediator Number Verification​

  • Commands must come from: Exact Mediator phone number
  • Other senders: Commands from other numbers automatically ignored
  • Verification: App checks sender number before processing
  • Number format: Must match exactly as entered

Background & Battery​

Battery Optimization Exemption​

  • Purpose: Keep app running reliably in background
  • Critical for: Receiving calls and SMS commands
  • How to set (Android varies):
    1. Go to Settings > Battery or Power
    2. Find "Battery Optimization"
    3. Locate SRT Let's Talk
    4. Select "Don't Optimize"
    5. Save changes

Samsung Device Setup​

  • Battery optimization: Especially important on Samsung
  • During setup: Follow Battery Optimization screen
  • Later access: Settings > Battery > More Options
  • Result: App won't be killed when screen off

Overlay Permission​

  • Purpose: Allow widget to work in background
  • Critical for: Home screen LINE button widget
  • How to grant:
    1. Phone Settings > Apps > Special Access
    2. Find "Display over other apps"
    3. Enable for SRT Let's Talk
  • Alternative path: Settings > Apps > SRT Let's Talk > Permissions > Overlay

Notification Settings​

Notification Sounds​

  • On/Off: Toggle notifications in app settings
  • Sound: Choose default or custom notification sound
  • Vibration: Toggle vibration on/off
  • LED: Enable/disable LED light notifications

Do Not Disturb​

  • Bypass DND: SRT Let's Talk notifications bypass Do Not Disturb mode
  • Emergency calls: Always come through
  • Configuration: May vary by Android version

Accessibility​

Text Size​

  • Device-wide setting: Use phone's Accessibility > Text Size
  • App follows: SRT Let's Talk respects phone text size settings
  • Larger text: Helps visibility for users with vision needs

Display Settings​

  • Brightness: Adjust phone brightness for better visibility
  • Dark Mode: Some Android versions support dark theme
  • High Contrast: Some phones offer high contrast mode

Advanced Settings​

App Information​

  • Version: Shows current app version
  • Package Name: com.srtletstalk
  • Storage Used: Total app storage consumption
  • Cache: Can clear cache if app slow

Send Logs to Support​

  • Purpose: Share debugging information with support team
  • How to use:
    1. Go to Settings > About
    2. Tap "Send Logs to Support"
    3. Email application opens
    4. Describe your issue
    5. Send to support@ideatech.us
  • Contents: App logs, device info, error messages
  • Privacy: Only sent when you explicitly choose

Reset to Defaults​

  • Available in: Some Android versions
  • Effect: Resets all settings to factory defaults
  • Data loss: Deletes all recorded videos and settings
  • Warning: Cannot undo - confirm before proceeding

PIN Recovery​

Forgot your PIN?

Unfortunately, there is no self-service PIN reset option. This is intentional for security:

  1. Contact Support:

    • Email: support@ideatech.us
    • Phone: (708) 808-0719

  2. Provide:

    • Your license key
    • Device information
    • Photo ID or proof of ownership

  3. After Verification:

    • Support can reset your PIN
    • You'll set a new PIN via app

  4. Timeline: Usually 24-48 hours

Settings Tips​

  • Backup PIN: Write PIN somewhere secure (not in phone)
  • Test Settings: Test each feature after configuration
  • Server URL: Verify server URL carefully before saving
  • Contacts: Add backup contacts if possible
  • Permissions: Grant all requested permissions for best operation
  • Regular Updates: Check for app updates regularly
