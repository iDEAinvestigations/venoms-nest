SRT Let's Talk - SMS Commands Reference

Overview​

The Mediator can remotely control the app by sending SMS commands. If a PIN is configured, prefix all commands with the PIN followed by a space.

Command List​

CommandFunction
HELPGet list of all available commands
STARTStart streaming/check-in
STOPStop streaming
STATUSGet current app status
LOCATIONRequest current GPS location (includes floor)
FLIPSwitch between front/back camera
FRONTSwitch to front camera
BACKSwitch to back camera
AUDIO ONLYSwitch to audio-only mode (low bandwidth)
VIDEOSwitch back to video+audio mode
RECORD ONStart recording
RECORD OFFStop recording
CALL MEPhone calls the Mediator with black screen

Examples With PIN​

If your PIN is "7890":

7890 STATUS

→ Get streaming/recording status

7890 START

→ Start the live stream

7890 LOCATION

→ Get GPS coordinates with floor level

7890 FLIP

→ Switch camera between front and back

7890 AUDIO ONLY

→ Switch to low-bandwidth audio-only mode

7890 RECORD ON

→ Start recording the stream

7890 CALL ME

→ Initiate call back with black screen

Examples Without PIN​

If no PIN is configured:

STATUS

→ Get streaming/recording status

START

→ Start the live stream

LOCATION

→ Get GPS coordinates with floor level

FLIP

→ Switch cameras

STOP

→ Stop streaming

HELP

→ Get help with commands

Command Tips​

Formatting Rules​

  • Commands are case-insensitive (STATUS = status = Status)
  • Include PIN prefix if configured: "PIN COMMAND"
  • If using PIN, space must follow PIN: "7890 STATUS" ✓ (not "7890STATUS")
  • Command must come from exact Mediator phone number

Best Practices​

  • Test each command before emergency situations
  • Verify PIN is working correctly
  • Ensure Mediator has correct phone number
  • Check that SMS permissions are granted
  • Enable Auto-Delete for privacy

Troubleshooting Commands​

Commands Not Working:

  1. Verify Mediator number matches exactly in settings
  2. Check if PIN is configured - include PIN prefix if set
  3. Ensure SMS permissions are granted to app
  4. Messages must come from registered Mediator number
  5. Check internet connection (some responses require data)

Location Not Returning:

  1. Enable GPS/Location services
  2. Grant location permissions
  3. Go outside or near window for GPS signal
  4. Calibrate floor detection if needed

Recording Not Starting:

  1. Check if storage space available
  2. Verify recording folder is set correctly
  3. Enable Auto-Record in settings
  4. Ensure camera permission granted

Camera Commands​

FLIP Command​

  • Switches between front and back camera
  • Useful for changing perspective
  • Works during streaming or recording
  • Response confirms camera switched

FRONT Command​

  • Forces use of front camera
  • Remains on front until switched
  • Use before starting stream to ensure front camera

BACK Command​

  • Forces use of back camera
  • Better for wide-angle perspectives
  • Use before starting stream to ensure back camera

Streaming Mode Commands​

AUDIO ONLY Command​

  • Reduces bandwidth usage significantly
  • Useful on slow connections
  • Audio quality remains full
  • Good for low-speed situations

VIDEO Command​

  • Switches back to video+audio mode
  • Returns to previous resolution setting
  • Full quality streaming resumed
  • Requires more bandwidth

STOP Command​

  • Immediately stops all streaming
  • Stops any active recording
  • Notifies all Viewer contacts
  • Quick way to end streaming

Emergency Commands​

CALL ME Command​

  • Initiates call back to Mediator with black screen
  • Phone rings as normal incoming call
  • Screen remains black (no display of calling activity)
  • Useful for covert communication

STATUS Command​

  • Quick check of app status
  • Returns current operational state
  • Helps verify app is running
  • No side effects (just reads status)

LOCATION Command​

  • Requests immediate GPS location
  • Includes floor level if available
  • Returns Google Maps link
  • Updates immediately after calibration

Advanced Usage​

Combining Commands​

You cannot send multiple commands in one message, but you can:

  1. Send START command to begin streaming
  2. Follow with FLIP to switch camera
  3. Then LOCATION to get position

Example sequence:

Message 1: 7890 START
Message 2: 7890 FLIP
Message 3: 7890 LOCATION

Streaming Control​

For precise streaming control from Mediator:

7890 START           → Begin streaming
7890 AUDIO ONLY      → Switch to low bandwidth
7890 FLIP            → Change perspective
7890 STOP            → End stream

Recording Management​

Monitor recording without interrupting stream:

7890 STATUS          → Check if recording
7890 RECORD ON       → Start recording
7890 RECORD OFF      → Stop recording

Security Considerations​

PIN Prefix Protection​

  • Prevents unauthorized SMS control
  • Commands without PIN ignored if PIN enabled
  • Unique PIN recommended (not 1234 or 0000)
  • Change PIN periodically

Auto-Delete Feature​

  • Automatic SMS deletion after processing
  • Invisible command history
  • Only works with SMS permissions
  • Response messages still sent normally

Number Verification​

  • Commands must come from Mediator number
  • Exact match required
  • Commands from other numbers ignored
  • Mediator number must be in Emergency Contacts
