MacVenom Pro - Advanced Features

Export & Data Management​

Exporting Scan Results​

You can save scan results for analysis:

  1. After completing a scan, tap the Export button
  2. Choose your format:
    • CSV: Open in Excel or spreadsheets
    • JSON: For technical analysis
    • PDF: For reports or sharing
  3. Select save location
  4. Results are saved with timestamp

CSV Export Contents​

Exported CSV includes:

  • Device names
  • MAC addresses
  • Signal strength (RSSI)
  • Estimated distance
  • Device type
  • Scan timestamp

Advanced Settings​

Access Advanced Settings by tapping the ⚙️ gear icon:

Scanner Settings​

  • Scan Frequency: How often app rescans (5s, 10s, 30s intervals)
  • Minimum Signal: Filter out weak signals below certain dBm
  • Update Interval: How often device list refreshes
  • Show Debug Info: Display technical RSSI details

Audio Settings​

  • Beep Volume: Adjust beeping volume (0-100%)
  • Beep Tone: Choose beep sound (high, medium, low pitch)
  • Mute in Silent Mode: Respect system mute switch
  • Audio Output: Use speaker or phone receiver

Haptic Settings​

  • Haptic Strength: Intensity of vibrations (low/medium/strong)
  • Pattern: Vibration pattern for alerts
  • Enable for Scanning: Vibrate when new devices found

Display Settings​

  • Theme: Dark mode or light mode
  • Font Size: Make text larger or smaller
  • Show Icons: Toggle device type icons
  • Metric Units: Show distance in meters instead of feet

Frequent Device Tracking​

Creating a Tracking Profile​

For devices you frequently search for:

  1. Find the device in a scan
  2. Tap "Add to Frequent List"
  3. Name the profile (e.g., "Lost Keys", "Friend's AirPods")
  4. Device appears in Frequent List

Accessing Frequent Devices​

  1. From home screen, tap "Frequent Devices"
  2. Your saved device profiles appear
  3. Tap any profile to immediately start DF
  4. Saves time for devices you regularly track

Batch Operations​

Rename Multiple Devices​

If you've discovered several devices you want to organize:

  1. From device list, tap Menu > Batch Rename
  2. Select multiple devices using checkboxes
  3. Apply a naming pattern (e.g., add prefix to all)
  4. Confirm batch rename

Clear Device History​

To remove old device records:

  1. Open Settings > Device History
  2. Tap "Clear History"
  3. Choose time period:
    • Clear last 24 hours
    • Clear last 7 days
    • Clear all history
  4. Confirm deletion

Signal Strength Analytics​

View Signal History​

To see how signal strength changes over time:

  1. From device list, long-press a device
  2. Select "View Signal History"
  3. Graph shows RSSI over last hour
  4. Helps identify signal patterns

Identify Signal Patterns​

The signal history graph helps you:

  • See if device is moving away or closer
  • Identify signal dead zones
  • Plan optimal searching routes
  • Detect device power cycling

Interference Detection​

MacVenom Pro can identify RF interference that affects scanning:

  1. Tap ⚙️ Settings > Advanced

  2. Enable "Interference Detection"

  3. App will flag sources of interference:

    • WiFi routers
    • Microwaves
    • Cell towers
    • Other RF sources

  4. These locations display as ⚠️ Interference Zones on map view

Map View (If Available)​

Displaying Devices on Map​

  1. From main screen, tap "Map" button
  2. All detected Apple devices display on map
  3. Tap any device to see details
  4. Long-press for options (DF mode, rename, etc.)

Map Features​

  • Zoom In/Out: See area in detail or get overview
  • Satellite View: Switch to satellite imagery
  • Search: Find specific addresses
  • Export Map: Save screenshot of device locations

Scanning Capabilities​

System Requirements​

  • Android Version: 8.0+ (API 26+)
  • Memory: Minimum 2GB RAM
  • Storage: 100MB free space
  • Permissions: Location, Bluetooth, Nearby Devices

Support & Feedback​

If you find bugs or have feature requests:

  1. Open Settings > Support
  2. Tap "Send Feedback"
  3. Describe your issue/suggestion
  4. Include device model and Android version
  5. Tap "Send"

Your feedback helps improve MacVenom Pro!
