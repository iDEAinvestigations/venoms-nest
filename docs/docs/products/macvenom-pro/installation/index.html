MacVenom Pro Installation & Activation

System Requirements​

  • Android 8.0 or higher
  • Bluetooth Low Energy (BLE) capable device
  • Location services capable
  • At least 100MB free storage
  • Valid MacVenom Pro license key

Installation Steps​

Step 1: Download the APK​

  1. Visit apps.ideatech.us
  2. Select MacVenom Pro
  3. Download the APK file to your Android device

Step 2: Enable Unknown Sources​

  1. Open Settings on your device
  2. Navigate to Security or Privacy
  3. Toggle on "Unknown Sources" or "Install Unknown Apps"
  4. Confirm any warnings

Step 3: Install the App​

  1. Open your Downloads folder
  2. Tap the MacVenom_Pro.apk file
  3. Tap "Install"
  4. Wait for installation to complete
  5. Tap "Open" or find the app in your app drawer

First Launch & Activation​

Initial Permissions​

When you first launch MacVenom Pro, you'll be prompted to grant permissions:

PermissionPurposeRequired
LocationGPS and network scanningYes
BluetoothBLE device scanningYes
Nearby DevicesEnhanced device detection (Android 12+)Yes
CameraOptional for QR code activationNo

Grant all required permissions to use all features.

License Activation​

  1. On the activation screen, enter your license key
  2. Format: Typically provided as XXXXXX-XXXXXX
  3. Tap "Activate"
  4. Wait for online verification
  5. Success message will appear
  6. App is now ready to use

Settings Configuration​

After successful activation:

  1. Review app settings (optional)
  2. Toggle features on/off as needed
  3. Configure audio/haptic preferences
  4. Begin scanning!

Troubleshooting Installation​

APK Won't Install

  • Ensure "Unknown Sources" is enabled
  • Check if you have sufficient storage (100MB minimum)
  • Try restarting your device

License Activation Fails

  • Verify internet connection
  • Check license key spelling
  • Ensure license hasn't expired
  • Contact support@ideatech.us if problems persist

App Crashes on Startup

  • Clear app cache: Settings > Apps > MacVenom Pro > Clear Cache
  • Restart your device
  • Reinstall the app

Uninstalling​

To uninstall MacVenom Pro:

  1. Open Settings > Apps
  2. Find and tap MacVenom Pro
  3. Tap "Uninstall"
  4. Confirm

All app data will be deleted.
