MacVenom Pro Troubleshooting

Scanning Issues​

No Devices Found in Scan​

Solutions:

  1. Enable Bluetooth: Settings > Bluetooth > Toggle ON
  2. Enable Location: Settings > Location > Toggle ON
  3. Grant permissions: App settings > Verify all permissions granted
  4. Move closer to Bluetooth devices
  5. Restart Bluetooth: Toggle off, wait 10 seconds, toggle on
  6. Restart app

Devices Disappearing from List​

Cause: Devices moved out of range

Solutions:

  1. Move closer to the device
  2. Rescan with refresh button
  3. Check if target device is still powered on
  4. Try different location with less interference

Too Many Unknown Devices​

Solution: Use the Filter option to show only Apple devices, reducing clutter

Directional Finding Issues​

Arrow Not Pointing in Right Direction​

Solutions:

  1. Calibrate Compass: Wave phone in figure-8 pattern
  2. Move Away from Metal: Metal objects interfere with compass
  3. Restart DF: Stop and start Directional Find again
  4. Re-Scan First: Perform a new scan before starting DF

Beeping Not Working​

Solutions:

  1. Check Volume: Ensure device volume is turned up
  2. Check Mute: Verify physical mute switch is off
  3. Check Settings: App > Audio Settings > Ensure beeping enabled
  4. Test Speaker: Try playing music to verify speaker works
  5. Restart App: Close and reopen app

Vibration Not Activating​

Solutions:

  1. Enable Haptic: In DF Mode, ensure Haptic button (📳) is highlighted
  2. Check Settings: App > Haptic Settings > Ensure enabled
  3. Test Vibration: Settings > About > Vibration Test
  4. Distance Check: Must be within 5 feet for haptic to trigger
  5. Device Issue: Phone's vibration motor may be faulty

Confidence % Too Low​

Meaning: The bearing is less reliable

Solutions:

  1. Get closer to the device (moves to better signal)
  2. Move to different location (avoid interference)
  3. Repeat scans to get better readings
  4. Wait a moment for signal to stabilize

"Check Above or Below" Message​

The device is very close but not in your immediate horizontal area

What to do:

  1. Look at ceiling/above current position
  2. Look at floor/below current position
  3. Check adjacent floors (stairs up/down)
  4. Check basement or attic
  5. Look in walls (if device is hidden)

License & Activation​

License Activation Fails​

Solutions:

  1. Check internet connection is stable
  2. Verify license key format and spelling
  3. Ensure license hasn't expired
  4. Try again after a few minutes
  5. Contact support@ideatech.us

"License Not Valid"​

Causes:

  • Key is expired
  • Key is for different product
  • Already used on 2 devices (one key per device typically)

Solutions:

  1. Contact sales for license renewal
  2. Verify you have correct product license
  3. Uninstall from other device if reusing key

App Says License Expired​

Solution: Contact Sales@ideatech.us to renew your license

Email them:

  • Your current license key (last 4 digits)
  • Request for renewal

Performance Issues​

App Runs Slowly​

Solutions:

  1. Free Storage: Ensure at least 500MB free space
  2. Restart Phone: Full device restart can help
  3. Clear Cache: Settings > Apps > MacVenom Pro > Clear Cache
  4. Reduce Scan Frequency: Lower update frequency in settings
  5. Close Background Apps: Close other apps running in background

App Crashes Frequently​

Solutions:

  1. Clear App Data: Settings > Apps > MacVenom Pro > Clear Data
  2. Restart Device: Full restart often fixes crashes
  3. Update Android: Check for OS updates
  4. Reinstall: Uninstall and reinstall the app
  5. Contact Support: If crashes continue

High Battery Drain​

Cause: Continuous Bluetooth scanning uses battery

Solutions:

  1. Lower Scan Frequency: Change to 30-second intervals
  2. Reduce Update Interval: Less frequent updates = less battery
  3. Disable Unnecessary Features: Turn off mapping, audio, haptic when not needed
  4. Battery Saver Mode: Enable phone's battery saver when not actively scanning
  5. Close App When Done: Don't leave running in background

Permissions Issues​

"Location Permission Denied"​

Solutions:

  1. Open Settings > Apps > MacVenom Pro
  2. Tap Permissions
  3. Tap Location
  4. Select "Allow all the time" or "Allow only while using the app"

"Bluetooth Permission Denied"​

Solutions:

  1. Open Settings > Apps > MacVenom Pro
  2. Tap Permissions
  3. Tap Bluetooth
  4. Tap to Allow

"Nearby Devices Permission Denied" (Android 12+)​

Solutions:

  1. Open Settings > Apps > MacVenom Pro
  2. Tap Permissions
  3. Tap "Nearby Devices"
  4. Tap to Allow

Data & Privacy​

App Won't Export Data​

Solutions:

  1. Verify you have file manager app installed
  2. Check storage space is available
  3. Try different export format (CSV, PDF, JSON)
  4. Grant storage permissions

Device Names Not Saving​

Solutions:

  1. Restart app to see if saved
  2. Try renaming again
  3. Check available storage space
  4. Uninstall and reinstall if problem persists

Network Issues​

Can't Reach Download Server​

For issues downloading the app:

Solutions:

  1. Check internet connection
  2. Try WiFi instead of cellular data
  3. Try again later (server may be down)
  4. Contact support for direct APK

App Update Issues​

Solutions:

  1. Uninstall current version
  2. Download latest APK
  3. Reinstall fresh version
